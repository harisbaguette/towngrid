# 환경·효과 컴포넌트

[환경·효과 미리보기](http://localhost:5173/world-effects-preview.html)에서 종류·지형·시점을 바꾸고 동작을 멈출 수 있다. 홈의 추가 메뉴에서도 연다. 이 화면은 표시 조건을 지정한 시험용 마을이며 게임을 저장하지 않는다. 차량은 실제 수출 경로로 출발한다.

| 컴포넌트 | 게임에서 나타나는 조건 |
| --- | --- |
| `FogLayer` / `CloudLayer` | 시작 지도·플레이의 이동하는 안개와 픽셀 구름 |
| `RainLayer` | 현재 거점의 폭풍 예고·발생 직후. 설원에서는 비를 그리지 않음 |
| `SnowLayer` | 카메라 주변의 실제 설원 지형 |
| `WindParticles` | 숲·습지의 잎, 사막·분지·화산의 먼지, 평야의 꽃가루 |
| `WaterRipples` | 실제 물 타일의 잔물결·반짝임 |
| `ShoreFoam` | 물 타일과 육지가 만나는 가장자리 |
| `BirdFlock` | 숲·평야·물가의 작은 새 떼. 폭풍 때 숨김 |
| `ChimneyPlumes` | 실제 가동 중인 시설의 기존 굴뚝 부품 위치 |
| `WorkParticles` | 실제 채굴·목공·고온 작업 중인 설비 |
| `VehicleTrails` | 움직이는 육상 수출·화물 차량. 설원에서는 눈가루 |
| `ActionBursts` | 건설·철거·이전·수리·피해·생산 완료가 발생한 위치 |
| `MagicField` | 가동 중인 마법 시설, 유지 중인 결계, 정전 중인 전력 시설 |
| `DayNightLighting` | 게임의 하루 주기와 폭풍에 따른 색조, 밤의 주택·가동 시설 불빛 |

`world-effects.js`가 컴포넌트를 게임 장면에 연결한다. `effect-batch.js`는 작은 효과 텍스처 한 장과 컴포넌트별 고정 크기 버퍼를 사용한다. 상세 효과는 가까운 지도에서 표시하고, 낮은 품질·모바일·Canvas에서는 환경 입자 수를 줄인다. 카메라 조작과 건설 선택을 가로채지 않는다.

시설의 작업 부품·작물·재고·배의 물결·파손 그림은 기존 컴포넌트가 담당한다. 새 효과는 실제 상태를 읽으며 생산량·날씨 피해·지형·저장 형식을 바꾸지 않는다. 거점 전환과 불러오기에서 과거 건설·수리 효과를 재생하지 않는다.

동작 줄이기에서는 환경 입자 이동을 멈추고 시설 변화의 일회성 입자를 생략한다. 미리보기의 동작 정지는 카메라 조작을 유지한다. 폭풍은 밝은 화면 점멸 없이 비·색조로 표시한다.

표현은 픽셀 입자와 반투명 평면 합성이다. 입체 유체·적설·침수·화재 전파를 시뮬레이션하지 않는다. Canvas는 지면 효과를 시설 아래, 공중 효과를 시설 위에 합성하므로 WebGL의 가림 결과와 차이가 날 수 있다. 캐릭터의 신규 동작 원화 작업 상태는 별도 [캐릭터 동작 목록](CHARACTER_ANIMATION_CHECKLIST.md)을 따른다.

검사 명령: `node tests/world-effects.mjs`. 실행 중인 개발 서버에서 `node tests/world-effects-browser.mjs <playwright/index.mjs> <chrome.exe>`로 각 효과·상태 전환·회전·모바일·Canvas를 확인한다.
