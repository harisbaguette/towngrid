# 첫 1시간 플레이 점검

이 게임을 처음 보는 사람 5명이 각각 새 게임을 시작한다. 목표는 **5명 중 4명이 실제 플레이 60분 안에 8단계에 도달하는 것**이다. 자동 봇이나 한 사람의 반복 플레이를 서로 다른 참가자의 결과로 세지 않는다. 실제 참가자 결과는 아직 없다.

참가자에게는 “빈 땅에서 생산과 판매를 시작하고 8단계까지 성장하세요”라고만 설명한다. 관찰자는 버튼 위치나 건설 순서를 알려 주지 않는다. 참가자가 직접 설정에서 안내를 켜는 것은 허용하고 기록한다. 원하는 배속을 사용한다.

메뉴의 **플레이 점검 기록**에는 첫 건설·첫 판매·승급·메뉴 발견 시간이 남는다. 화면이 보이는 동안의 시간이며, 창을 떠난 시간은 제외한다. 최근 10회만 이 브라우저에 보관하고 서버에 전송하지 않는다. 점검 후 **점검 기록 내려받기**로 JSON 파일을 받는다. 저장 불러오기·시연·산업 도전은 새 참가자 기록을 만들지 않는다.

기록과 함께 익명 참가자 번호, 사용 기기·화면 크기, 선택한 국가, 사용 배속, 안내를 켠 시각, 멈춘 이유를 적는다. 관찰자가 개입했다면 시각과 설명한 내용을 남긴다. 60분이 지나거나 참가자가 중단하면 마지막 단계와 원인을 기록한다.

4명이 통과하지 못하면 실패가 가장 많이 모인 행동부터 고친다. 다음 점검에는 이미 길을 아는 참가자를 재사용하지 않는다. 모바일은 실제 기기의 발열·메모리 부족·터치 조작도 확인한다. 브라우저의 모바일 화면 크기 재현만으로 실기기 점검을 대신하지 않는다.
