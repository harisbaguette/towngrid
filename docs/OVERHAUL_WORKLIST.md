# 에르딘트 수정 작업표

구현한 변경과 검증하지 못한 부분을 나눈다. 아래 완료 표시는 출시 품질 전체에 대한 승인을 뜻하지 않는다.

- [x] 선박과 소품의 모서리 곡률, 재질과 조명 수정
- [x] 주민의 작업복·마도복·갑옷 구분, 드워프 체형, 손·부츠 수정
- [x] 제련·채유·정유 시설 형태 변경, 완제품 적재 표현
- [x] 부두는 육지 한 칸, 작업선은 가장 가까운 수면에 배치
- [x] 집기·내리기 애니메이션, 이동 속도에 맞춘 보행, 위치 음향
- [x] 지도 경고·원인 안내·빠른 납품·감염 대응
- [x] 시설 간 직송, 도착 시 집기, 예약 재고, 시장 수요와 회복
- [x] 운영 시험과 사업 헌장, 다섯 단계 가족 구출
- [x] 지속 감염과 치료, 현장 경비대와 결계 범위, 실제 영토 분할
- [x] 재고 보존·저장 호환·장기 진행·원본 3D 렌더 검수
- [ ] 변경된 UI를 실제 브라우저에서 직접 조작해 확인
- [ ] 실제 기기에서 소리 균형과 터치 조작 검수
- [ ] 사용자가 원하는 최종 에셋 품질에 도달했는지 평가

미리보기 실행은 두 차례 시간 초과로 종료되었다. 직접 플레이나 실제 청감을 확인했다고 간주하지 않는다.
