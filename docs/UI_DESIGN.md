# TownGrid UI

UI는 **산업 제어반 3번 시안**의 청록색 에나멜 프레임·크림색 패널·주황색 입체 버튼을 사용한다. 배치는 미니멀 시안을 따르며 지도 공간을 우선한다. 컴포넌트 규격은 [디자인 시스템](DESIGN_SYSTEM.md), 배치 기준은 [미니멀 시안](http://localhost:5173/ui-layout-concepts/index.html)에서 확인한다.

## 화면 배치

### 게임을 열 때

대기 화면은 승인된 로고와 픽셀 배경, 시작 버튼 하나를 보여 준다. 홈의 첫 버튼은 저장이 있으면 `이어하기`, 없으면 `새 게임`이다. `마을의 하루`는 바로 열고, 시연·작화·지형 테스트는 `체험·점검`을 펼쳐 찾는다.

홈·갤러리·로딩·전환·복구 화면의 배치는 `start-screens.css`에서 관리한다. 홈과 게임의 버튼·프레임은 `component-art.css`의 공통 이미지 자산을 쓴다. 로딩에는 진행률 숫자 대신 분절형 움직이는 게이지를 표시한다. 그래픽 복구 화면에서는 진행 파일을 직접 내려받을 수 있다.

### 마을 화면

- 좌상단: 돈·목재·석재. 화살표로 주요 재고를 펼치고, 돈을 누르면 장부를 연다.
- 우상단: 날짜·일시정지·배속·메뉴. 배속을 누르면 1·2·4배속을 고른다.
- 하단 중앙: 시장·건설·세계. 건설은 `B`, 취소는 `Esc`다.
- 건설 중에는 하단 메뉴 자리에 기초·생산·운송 목록이 열린다. 추가 분류와 해금 전 시설은 분류 선택에서 찾는다.
- 시설을 선택하면 같은 자리에 이름·가동 상태·실제 생산 진행과 완성품 수량을 표시한다. 상세 버튼에서 생산법·수리·이전·철거 등을 조작한다.
- 목표·계약·운영 알림·주민·영토 확장·주변 지형·지도 도구·설정은 우상단 메뉴에서 연다. 기본 지도에는 문제가 있는 시설의 작은 표식을 표시한다.
- 모바일은 자원을 첫 줄, 시간과 메뉴를 두 번째 줄에 둔다. 하단 조작부는 한 번에 하나만 표시하며 건설 목록은 가로로 넘긴다.

## 메뉴 안의 화면

- 시장은 상품 검색·주문 수량·재고·판매를 먼저 보여 준다. `보유만`으로 재고가 있는 상품을 추리고, `운송·보관`에서 교역 도시·터미널·창고를 설정한다. 자동 판매를 켠 상품에는 최소 보관량을 표시한다.
- 목표는 `승급·납품`과 `빚·가족·자치`로 나눈다. 전체 승급 단계는 접어 둔다.
- 설정은 `소리·화면`과 `저장·불러오기`로 나눈다. 소리 시험·초기화와 이전 저장 복구는 각각 펼쳐서 사용한다.
- 주민은 현재 활동과 주민 목록을 먼저 보여 준다. 방향·동작 버튼은 `동작 미리보기`에서 연다.
- `거점·외교`에서 국가·지형으로 부지를 찾는다. `월드에서 이 땅 보기`는 관리 창을 닫고 같은 월드의 해당 위치로 카메라를 이동한다. 진출 조건과 운영 버튼은 선택 부지 아래에 둔다.
- 상세 창은 크림색 바탕과 얇은 구분선을 쓰고, 탭은 주황색 밑줄로 구별한다. 제목과 닫기 버튼은 스크롤 중에도 보인다.

상세 창의 공통 외형은 `game-dialogs.css`, 시장과 설정은 `game/MarketPanel.tsx`·`game/SettingsPanel.tsx`에서 관리한다.

## 세계 지도

새 게임은 **국가 선택 → 빈 부지 선택 → 실제 땅 미리보기** 순서다. 지도 한 칸은 24×24 마을이다. 선택 국가와 주변 국가가 보이는 범위에서 시작하고, 축소하면 대륙 전체를 볼 수 있다. 지도에서 국가를 고른 뒤 `지역 살펴보기`, 빈 칸을 고른 뒤 `땅 미리보기`를 누른다. 마지막 화면에서 인족·엘프족을 고르고 `이 땅에서 시작`을 누른다. 뒤로 가면 선택한 부지를 유지한다.

시작 지도는 플레이와 같은 월드 캔버스를 사용한다. 왼쪽 위는 뒤로 가기와 현재 단계, 하단 중앙은 선택 정보와 다음 버튼이다. 국가·부지 목록은 `지형으로 찾기`, 정책·주변 지형·자원 정보는 `?` 또는 `자세히`에서 연다. 선택 부지는 금색 테두리, 정착 제한은 선택 정보에 표시한다. 종족은 아이콘과 밝은 밑줄로 구별한다. 확대해도 지명 글자 크기를 유지하고 겹치는 이름은 숨긴다.

마우스 드래그로 이동하고 휠·+/− 버튼으로 내 땅부터 대륙까지 확대·축소한다. 모바일은 한 손가락 이동과 두 손가락 확대를 지원한다. Q/E와 회전 버튼은 90도씩 시점을 바꾼다. 지도에 초점을 둔 상태에서 방향키는 월드의 칸 단위 이동, Enter는 중심 부지 선택, Home은 대륙 전체 보기다. 오른쪽 집 버튼은 현재 내 땅으로 돌아오고, 다른 보유 부지의 `이 거점 운영`은 같은 월드 안에서 운영 대상을 바꾼다.

새 게임은 비수도권의 빈 땅에서 시작한다. 에스테른의 기본값은 강과 숲에 접한 비옥한 평야인 하벤 남부 평원이다. 수도 칸·기존 정착지·정착 제한 구역·산·수역·적대 세력에서는 시작 버튼이 비활성화된다. 왕실 직할지·군사 구역·보호구역은 자물쇠, 산·수역은 ×로 구별하며 선택하면 제한 사유를 보여 준다.

대국 4개와 소국 10개를 두고, 소국은 모든 대국보다 좁은 영토를 가진다. 국경은 국가색으로 구별하며 선택한 부지는 금색으로 표시한다.

숲·평야·습지·광산 분지는 국가 경계를 넘어 섞이고 설원·사막은 작은 기후 구역으로 남는다. 지도 외곽은 같은 지면과 식생이 이어지는 비선택 풍경으로 채운다. 외곽 풍경에는 부지·소유권·건설 기능이 없다. 기존 저장의 땅·식생·자원은 저장된 값을 사용한다.

국경 밖에는 어느 국가에도 속하지 않은 무주지를 남긴다. 무주지에 국가색이나 별도 국경을 붙이지 않으며, 큰 미개척 지역에는 `무주지`라고 쓴다. 선택 칸 정보는 소속 국가와 개발 여부를 따로 보여 준다. 국경 안의 빈 땅은 `미개발지`, 밖은 `미개척지`다. 수도·기존 마을과 실제 시설이 있는 플레이 거점만 건물 스프라이트로 표시한다. 빈 부지를 선택해도 자연 지형이 유지되고, 부지만 확보한 거점에는 경계만 표시한다.

새 게임은 소속 국가 안의 정착 가능한 미개발지에서 시작한다. 무주지를 선택하면 실제 지형 미리보기와 개척 조건을 보여 준다. 게임 중 지역 선택창의 `무주지`에서 부지를 골라 광역 투자자부터 해외 진출과 같은 비용으로 확보한다. 확보한 24×24 칸은 **내 변경 영지**로 표시하며, 금색 경계는 맞닿은 보유 칸끼리 이어진다. 주변 칸은 무주지로 남는다. 지역 선택창의 `내 변경 영지`에서 보유 부지로 이동한다.

**지형 찾기**는 설원·평야·숲·광산 분지·사막/유전·모래 해안·갈대 습지·화산 고원의 실제 미개발 부지를 선택한다. 세계 지도 지면도 해당 생태 지형에 맞는 색을 사용한다. 사막과 화산 고원은 무주지에 있으며 새 게임 화면에서는 성장 후 개척 대상으로 안내한다.

세계 지도는 약 35.264도의 고정 아이소메트릭이다. 지면·국경·물길·선택 테두리가 함께 회전하고, 기존 환경 픽셀 자산을 같은 위치에서 표시한다. 가까운 지면과 먼 지면은 같은 타일 데이터를 읽으며 국가 이름은 먼 범위에서, 부지 이름은 가까운 범위에서 보인다. 구현 구조는 [연속 월드](WORLD_MAP.md)를 참고한다.

마을에 들어가면 24×24 영역과 주변 땅을 함께 보여 준다. 지면과 물가는 영역 안팎으로 이어지고, 얕은 물의 색 띠는 실제 물가를 따른다. 내 영역 전체는 짙은 바탕의 금색 실선과 굵은 모서리로 강조한다. 주변 24×24 부지에는 옅은 점선, 내 영역 안에서 확보한 땅에는 밝은 점선을 쓴다. 건설할 때 작은 격자가 나타나며 미확보 나무와 바위의 색은 살짝 옅게 표시한다.

시작 직전에는 선택한 땅과 실제 이웃 부지를 함께 보여 준다. 시작 버튼은 같은 캔버스와 카메라 위치를 유지한 채 건설·생산을 활성화한다. 안개는 카메라에서 멀어질수록 생기며 내 땅 경계에 고정하지 않는다. 상세 정보의 작은 미리보기에서는 지형·비옥도·광물·원유를 전환한다. 보유 거점은 저장된 시뮬레이션을 읽고, 시작 전 탐색은 게임을 진행하거나 저장하지 않는다.

게임 중 지도에서는 진출할 부지를 직접 고른다. 자금·목재·석재·물의 보유량과 필요량, 승급 제한을 표시하고 조건을 만족할 때만 선택한 칸에 거점을 만든다. `site-expansion.js`의 같은 계산을 표시와 실제 거래가 공유한다. 국내 법인 대표/해외 광역 투자자 조건과 가격은 기존 값 그대로다.

## 최적화와 검증

- `scripts/pack-world-atlas.mjs`가 실제 1,550칸의 지면을 `ground.webp`, 북향 미니맵을 `terrain.webp`로 합성한다. `pack-atlas-directions.mjs`가 원화에서 16종×4방향 그림을 추출한다. 세계 지도에서는 지면 이미지와 물체 그림을 분리해 투영한다.
- `atlas-surface.js`가 지도 안팎의 지면을 함께 계산한다. `pack-atlas-outskirts.mjs`는 가까운 외곽 `surrounds.webp`와 먼 배경 `outskirts.webp`를 만들며 상위 패커가 함께 실행한다.
- `tests/start-map.mjs`는 부지·기존 저장 호환, 국가별 시작 지형, 미리보기 일치와 외곽 범위를 검사한다. `tests/start-map-browser.mjs`는 실제 시작 단계·종족 선택·회전·5가지 화면 크기를 확인한다.
- `atlas-geometry.js`는 국가 경계와 좌표 조회를 제공한다. 지형·무역선은 `memo`로 분리하고, 거점 표시는 현재 보이는 범위로 제한한다. 미리보기는 부지나 seed가 바뀔 때만 새로 생성한다.
- 원화는 `art-source/world-atlas/`, 실행용은 `public/assets/world-atlas/`다. 원본이나 세계 격자를 바꾸면 `node scripts/pack-world-atlas.mjs`를 실행한다. 명세의 해시를 검사해 지형 데이터와 이미지 불일치를 찾는다.
- `npm run typecheck`, `npm test`, 프로덕션 빌드를 확인한다. 지형 누락·선택 좌표·경계·확대 범위는 `tests/atlas-geometry.mjs`, 물길 연결·글자 겹침·미리보기와 실제 생성 일치·진출 거래는 `tests/world-atlas.mjs`가 검사한다. 네 시점의 좌표·원화 해시는 `tests/atlas-isometric.mjs`, 실제 회전·클릭·모바일 표시는 `tests/atlas-isometric-browser.mjs`로 확인한다.
- `tests/minimal-ui-browser.mjs`는 실제 건설·시설 가동·상세 설정·메뉴·시장·세계 지도와 1440×960·1024×768·390×844·360×740·844×390 화면의 조작부 겹침·접근을 확인한다.

실제 캡처와 검사 결과는 `docs/verification/ui-20260929/`, 새 세계 지도는 `docs/verification/world-atlas-v2/`에 있다. `tests/world-atlas-browser.mjs`는 새 원화·확대별 글자·터치 확대·실제 거점 생성과 이동을 확인한다. 브라우저 검사는 기존 Playwright와 Chrome 경로를 인수로 받으며 사용자 브라우저와 별도의 저장 공간에서 실행한다. 저사양 실기기 FPS와 장기 경제 균형은 이번 UI 검사의 범위가 아니다.
