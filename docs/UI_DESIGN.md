# TownGrid UI · 2026-09-29

미라의 크림색 옷, 짙은 외투와 윤곽선, 황동 장식에서 화면 색을 가져왔다. 기존 픽셀 로고·인물·건물·자원 원화를 그대로 사용한다.

## 화면 배치

- 좌상단: 주민 초상, 현재 국가와 거점. 누르면 세계 지도가 열린다.
- 상단: 돈과 주요 자원. 공간이 부족하면 자원 줄을 가로로 넘긴다.
- 우상단: 승급 진행과 지금 할 일.
- 하단 중앙: 시장·건설·확장·세계. 건설은 `B`, 취소는 `Esc`다.
- 하단 양쪽: 주변 지형과 카메라. 건설 목록은 고정 조작부 위에 열린다.
- 모바일: 자원을 두 번째 줄에 배치하고 시설 정보와 건설 목록을 아래쪽에 표시한다. 짧은 가로 화면에서는 건설 중 목표 패널을 접어 분류 버튼을 가리지 않는다.

## 세계 지도

새 게임에서는 대륙 전체를, 게임 중에는 현재 국가 주변을 먼저 보여준다. 지도 한 칸은 24×24 마을이다. `대륙 전체` → 국가 이름 → `주변 확대` 순서로 범위를 좁힐 수 있다. 확대해도 지명 글자 크기는 유지하며, 겹치는 이름은 우선순위에 따라 숨긴다. 확대 중에는 오른쪽 위 미니맵으로 현재 범위를 확인한다.

지도는 카드 전체를 채우고 조작부는 지도 위에 떠 있다. 왼쪽 위는 범위 경로, 오른쪽 위는 무역로와 미니맵, 왼쪽 아래는 선택 칸 정보·주변 확대와 범례, 오른쪽 아래는 확대 버튼이다. 국가·물길 이름은 판 없이 외곽선 글자로 땅 위에 쓰고, 거점 이름만 작은 판을 쓴다. 이름은 떠 있는 조작부 밑으로 들어가지 않는다. 휴대폰에서는 대륙 전체가 폭에 맞고, 선택 칸 정보는 지도 아래로 내려간다. 새 게임 화면 위에는 로고·대륙 이름·`시작 지역 고르기`만 둔다. 오른쪽 시작 지역 창은 국가·지역 선택, 지역 이름과 생태 지형, 네 방향이 표시된 실제 24×24 미리보기 순서다.

마우스 드래그로 이동하고 휠·+/− 버튼으로 확대한다. 모바일에서는 한 손가락으로 이동하고 두 손가락으로 확대한다. 키보드는 방향키로 칸 이동, Enter로 선택 칸 주변 확대, +/−로 확대·축소, Home으로 대륙 전체를 본다. 무역로 버튼으로 도로와 항로를 켠다. 이미 보유한 다른 거점을 선택하면 `거점 이동`으로 들어갈 수 있다.

시작 국가는 오른쪽 선택창이나 지도에서 고른다. 새 게임은 비수도권의 빈 땅에서 시작한다. 기본값은 외곽 개척지이며, 국가별 5개 비수도권 거점 중 하나를 지역 선택창이나 지도에서 고를 수 있다. 선택한 칸의 지형·네 방향 안내와 실제 생성 위치가 일치한다. 수도권·산·수역·거점이 아닌 칸·적대 세력에서는 시작 버튼이 비활성화된다. 기존 저장의 위치는 바꾸지 않는다.

숲·산·사막·설원·습지·화산과 수도·깃발·마을·적대 요새는 세계 지도 전용 픽셀 원화를 사용한다. 바다와 담수 물길은 실제 이웃 칸을 읽어 해안선과 강줄기를 연결한다. 수도는 성, 시작/진출 후보는 깃발, 보유 거점은 마을로 구별한다. 승급 전 부지에는 잠금 표식을 붙인다.

오른쪽의 24×24 미리보기는 실제 `Simulation` 생성기로 만든다. 지형·비옥도·광물·원유를 전환할 수 있고 확보한 땅의 경계와 네 방향 지형을 보여준다. 신규 부지는 실제 생성 때 사용할 seed, 보유 거점은 현재 시뮬레이션을 읽는다. 미리보기는 게임을 진행하거나 저장하지 않는다.

게임 중 지도에서는 진출할 부지를 직접 고른다. 자금·목재·석재·물의 보유량과 필요량, 승급 제한을 표시하고 조건을 만족할 때만 선택한 칸에 거점을 만든다. `site-expansion.js`의 같은 계산을 표시와 실제 거래가 공유한다. 국내 법인 대표/해외 광역 투자자 조건과 가격은 기존 값 그대로다.

## 공용 디자인 값

정본은 `src/app/design-tokens.css`다. 새 UI에도 이 변수를 사용한다.

| 변수 | 값 | 용도 |
| --- | --- | --- |
| `--ui-ink` | `#293e36` | 본문·제목 |
| `--ui-paper` | `#f6f1de` | 기본 패널 |
| `--ui-paper-deep` | `#e8e2cb` | 입력·보조 영역 |
| `--ui-forest` | `#365c4b` | 주 행동·활성 상태 |
| `--ui-gold` | `#e3b85f` | 건설·중요 선택 |
| `--ui-outline` | `#34483c` | 외곽선 |
| `--ui-rule` | `#c8c4ab` | 내부 구분선 |
| `--ui-radius` | `6px` | 패널 모서리 |

화면 배치는 `game-ui.css`, 주민·시설·운송의 상세 배치는 `game-panels.css`에 있다. 버튼은 명확한 글자와 아이콘을 함께 쓰고, 원화에는 `image-rendering: pixelated`를 적용한다. 추가 장식보다 지도와 건물을 볼 공간을 우선한다.

## 최적화와 검증

- `scripts/pack-world-atlas.mjs`가 실제 1,550칸의 지형과 원화를 3200×1984 WebP 한 장으로 미리 합성한다. 지형 그룹은 이미지와 격자를 포함한 하위 요소 5개다. 기존 36개 대비 DOM이 줄었지만, 이미지 다운로드·디코딩 비용이 생기므로 FPS 개선율을 뜻하지 않는다.
- `atlas-geometry.js`는 국가 경계와 좌표 조회를 제공한다. 지형·무역선은 `memo`로 분리하고, 거점 표시는 현재 보이는 범위로 제한한다. 미리보기는 부지나 seed가 바뀔 때만 새로 생성한다.
- 원화는 `art-source/world-atlas/`, 실행용은 `public/assets/world-atlas/`다. 원본이나 세계 격자를 바꾸면 `node scripts/pack-world-atlas.mjs`를 실행한다. 명세의 해시를 검사해 지형 데이터와 이미지 불일치를 찾는다.
- `npm run typecheck`, `npm test`, 프로덕션 빌드를 확인한다. 지형 누락·선택 좌표·경계·확대 범위는 `tests/atlas-geometry.mjs`, 물길 연결·글자 겹침·미리보기와 실제 생성 일치·진출 거래는 `tests/world-atlas.mjs`가 검사한다.
- `tests/ui-design-browser.mjs`는 국가·종족·확대·드래그·휠·무역로·게임 진입·확장·시장·주민·세계 지도, 1440×900·1024×768·390×844·360×740·844×390 화면의 버튼 접근을 확인한다.

실제 캡처와 검사 결과는 `docs/verification/ui-20260929/`, 새 세계 지도는 `docs/verification/world-atlas-v2/`에 있다. `tests/world-atlas-browser.mjs`는 새 원화·확대별 글자·터치 확대·실제 거점 생성과 이동을 확인한다. 브라우저 검사는 기존 Playwright와 Chrome 경로를 인수로 받으며 사용자 브라우저와 별도의 저장 공간에서 실행한다. 저사양 실기기 FPS와 장기 경제 균형은 이번 UI 검사의 범위가 아니다.
