# 90도 간격 쿼터뷰 전환 — 2026-09-27

사용자의 최신 지시: 자유 회전을 없애고 네 방향 쿼터뷰로 통일하여 방향별 자산 제작량을 줄인다.

## 적용 상태

- 직교 카메라 방위는 45°, 135°, -135°, -45° 네 값으로 제한한다. 높이 각도는 약 35.264°로 고정한다.
- Q/E 또는 회전 버튼이 한 번에 90° 전환한다. 네 번 돌면 같은 위치와 방향으로 돌아온다.
- 좌우 마우스 드래그는 지도 이동, 휠/버튼은 확대, 한 손가락은 이동, 두 손가락은 확대/이동이다. 자유 궤도 회전은 차단한다.
- 주민·경비·적대 캐릭터 표시 방향은 SW/NW/NE/SE 네 가지다. 임의 각도의 공격 대상도 가장 가까운 표시 방향을 사용한다. 물류 경로·전투 위치·저장 형식은 이 방향 선택 때문에 바꾸지 않는다.
- 주민 패널과 시작 종족 미리보기, 미라 승인용 시안의 방향 보기도 네 방향으로 맞췄다.
- 기존 24종의 실행 아틀라스를 1024×1024 → 1024×512로 패킹했다. 24×64 = 1,536칸에서 24×32 = 768칸이다. 동일 동작에 필요한 방향별 그림도 8벌에서 4벌이 된다.
- 원본 8방향 PNG와 보정 명세는 보존한다. 기존 SW/NW/NE/SE 행의 RGBA 픽셀과 발 기준점이 재패킹 결과와 정확히 같은지 24종 모두 대조했다. 포트레이트는 교체하지 않았다.
- `scripts/pack-pixel-characters.py`가 원본 보정을 먼저 적용하고 네 대각선 행만 출력한다. 새 4방향 원본은 manifest의 `directions`를 `['SW','NW','NE','SE']`로 선언한다.
- WebGL UV, CPU 렌더러 자르기 좌표, UI 배경 크기 모두 프레임 메타데이터를 사용한다. 기존 8행 자산도 읽을 수 있으며 표시에는 대각선 네 행만 사용한다.

## 검증

- `npm run typecheck`, `npm test`, `npm run build` 통과.
- 카메라 자동 검사: 네 시점, 고정 높이, 자유 회전 차단, 네 번 회전 후 복귀, 줌·중심 유지.
- 캐릭터 자동 검사: 24종 768칸, 네 시점 × 네 이동 방향, 전투 임의 각도, 실제 WebGL UV/발 앵커와 CPU 이미지 자르기 좌표 대조.
- Chrome에서 네 시점의 맵 렌더링·지면 타일 선택, Q/E, 우클릭 드래그, 확대, 두 손가락 핀치 중 방위/높이 고정 확인.
- 주민 패널 네 버튼과 800%×400% UI 아틀라스 표시, 390px 모바일 회전 버튼, 미라 시안 네 방향 확인. 페이지 오류 없음.
- 실제 화면은 `view-0.png`부터 `view-3.png`, `resident-four-directions.png`, `mobile.png`에 있다. 브라우저 측정 기록은 `browser-check.json`이다.

기존 큰 JS 청크 및 Vinext 경로 분류 안내는 빌드에 남아 있다. 외부 배포는 하지 않았다. 이번 변경은 캐릭터의 새 화풍 승인이나 모션 원화 완성을 뜻하지 않는다. 기존 3포즈 걷기와 작업/공격 포즈 공유, 프레임 사이 비례 차이는 별도 개선 대상이다.
