# 에르딘트 수정 검수 기록 · 2026-09-26

이 문서는 원래 지적한 열 가지 문제에 대한 변경과 검증 범위를 기록한다. 출시판 완성 선언이 아니다.

| 문제 | 변경 | 확인 범위 |
|---|---|---|
| 참고 에셋과 다른 비례·재질 | 소품의 모서리 세분화, 조명과 CPU 반사광 수정 | 동일 GLB의 실제 게임 렌더로 형태 확인 |
| 동일한 캐릭터 몸체와 복장 | 드워프 체형, 앞치마·작업 재킷·마도복·갑옷, 손과 부츠 재작성 | 두 진영 로스터의 파일·동작·저장 검사; 캐릭터 렌더 확인 |
| 건물 기능이 읽히지 않음 | 제련로·펌프잭·정유탑을 서로 다른 실루엣으로 변경, 출고품 적재 | 제재·식품·제철·정유·첨단이 있는 장면 렌더 확인 |
| 배가 부두 위에 있음 | 부두는 육지 한 칸, 작업선은 가장 가까운 수역에 별도 배치 | 강변의 실제 GameScene 렌더 확인 |
| 집기·운반·소리가 따로 움직임 | 예약 후 현장에서 집기, 하역 지연, 집기·내리기 모션과 소리, 보행 속도 연동 | 재고 보존·모션 트랙·음향 매핑 검사. 실제 청감은 미확인 |
| 문제를 찾으려면 창을 열어야 함 | 지도 위 원료·출입구·전력 경고, 구체적 공급 원인, 빠른 납품과 방역 | 컴파일과 코드 검토. 변경 UI 직접 조작은 미확인 |
| 고정 시세와 창고 중심 물류 | 공장 간 직송, 운반 예약 재고 보호, 판매량에 따른 가격 하락과 수요 회복 | 빵 생산망·중도 철거·운반 중 저장·시세 회복 검사 |
| 승급과 가족 구출이 단순 지불 | 직송·무사 운영·치안 등 승급 시험, 세 가지 사업 헌장, 다섯 단계 구출 | 구출의 납품·채무·물자·경로·시간·주택 조건 및 장기 진행 검사 |
| 위기와 신생국이 추상 수치 | 지속 감염·방역·진료 물자, 경비대의 실제 접근과 공격, 마탑 국지 결계, 영토 소유권 | 치료 효과, 현장 방어, 분리 영토와 통행세·관계·저장 검사 |
| 테스트 통과를 재미·품질로 간주 | 자동 검증과 사람 검수 범위 분리 | 아래 제한을 명시 |

시설 하나는 계속 한 타일이다. 인족과 엘프족 모두 같은 산업에 진입한다. 대륙·세계 지도·거점·철도·회전·기존 저장 기능을 유지했다.

## 주요 규칙

- 주민은 원료가 있는 시설과 목적지를 골라 운반한다. 출발 시에는 예약만 하고 실제 집기 때 재고를 뺀다. 도중 철거와 작업 취소는 이미 들고 있는 물품만 반환한다.
- 같은 품목을 계속 팔면 판매 가격이 내려가며 시간이 지나면 회복된다. 원료를 넘길지 가공해 팔지, 급전을 마련할지 다른 품목으로 전환할지 선택한다.
- 초기 진료소는 물과 밀을 소비한다. 고도 산업의 감염은 의약품을 병원에 공급해야 한다. 방역은 즉시 감염을 줄이고 제한 시간 동안 추가 확산을 낮춘다.
- 가족 구출은 연락책 접촉 → 통행 협상 → 수레 준비 → 유료 검문소 또는 식량을 더 쓰는 강변 우회 → 실제 귀환 시간과 주택 확보 순서다. 기존 구출 완료 저장은 그대로 유지한다.
- 신생국은 모국의 실제 지방 영토를 가져간다. 그 영토의 거점에는 현지 시세·통행세·봉쇄가 적용된다. 우호 관계와 방위 협정은 조건을 개선한다. 모국에서 떨어진 후 다시 후계 국가가 나타나면 이전 국가의 영토 목록도 갱신한다.
- 경비대는 주둔지 주변에서 적에게 접근한다. 마탑의 결계는 범위 안의 적에게만 작용한다. 방위 수치만 높여서 화면 전역의 적 체력을 깎지 않는다.

## 검증과 제한

재고·생산·저장·구출·시장·감염·영토·방어의 자동 시나리오를 통과했다. 자원과 실적을 주입하지 않는 장기 자동 플레이는 33개 신분과 7개 거점을 진행했다. 자동 진행은 도달 가능성을 확인하며 사람의 재미 평가를 대신하지 않는다.

`revised-settlement-render.png`는 게임의 GameScene과 실제 GLB를 CPU 렌더러로 그린 것이다. 브라우저 UI 스크린샷이 아니다. `revised-assets-proof.png` 역시 배포하는 원본 GLB의 렌더다.

이 작업 중 실행 미리보기가 두 번 시간 초과로 종료되어 변경 UI의 직접 플레이·모바일 터치·실제 기기 음향 균형을 검수하지 못했다. 최종 에셋 품질이 사용자의 기대에 도달했다고 확정하지 않는다. 남은 검수는 `OVERHAUL_WORKLIST.md`에 열어 두었다.
