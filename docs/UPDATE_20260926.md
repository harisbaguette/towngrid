## 새 규칙

- 39종 시설. 새 자재 보관소·급수탑·풍력 발전기.
- 담수 관개는 밀밭 물 운반을 생략한다. 해수는 제외한다.
- 작동 가능한 공장의 오염, 높은 건물의 그늘, 제분/풍력 주변 장애물이 생산 효율을 바꾼다.
- 주요 산업 시설은 인접 도로가 필요하다. UI에 중단 이유를 표시한다.
- 자원별 보관 한도 기본 240개, 보관소마다 120개 증가. 창고가 가득 차면 생산품·운송 화물은 사라지지 않고 대기한다.
- 자동 판매는 원료·납품·운송 예약을 남기고 10개 단위로 진행한다.

## 실제 검증

- `tests/simulation.mjs`, `tests/fantasy.mjs`, `tests/campaign.mjs`, `tests/quality.mjs`, `tests/release.mjs`, `tests/overhaul.mjs` 통과.
- `tests/full-campaign.mjs`: 정상 플레이 행동만으로 41일·7거점·자동차 80대·32번 승급(최종 33단계). 결과는 `FULL_CAMPAIGN_RESULT.json`.
- `tests/asset-pose.mjs`: 복제한 티탄·말·로봇 리그의 실제 변형 정점 크기 확인. 티탄이 작아져 사라지던 초기 경계 상자 오류를 수정했다.
- 새 GLB 24개, 4,040,088바이트. 전달된 해시와 일치하며 외부 텍스처 의존성 없음.
- TypeScript 및 공백 오류 검사 통과. 프로덕션 빌드는 배포 단계에서 기록한다.
- Chrome 실제 UI: 두 종족 선택, 산업 시연, 빈 땅의 농노 시작, 시설 가동 스위치, 회전·확대, 소리 설정, 320/390픽셀 화면 확인.
- 스크린샷: `erdynth-world-final-20260926.jpg`, `erdynth-play-20260926.jpg`, `erdynth-mobile-20260926.jpg`.
- 브라우저는 하드웨어 WebGL 대신 같은 모델을 그리는 CPU 대체 경로를 사용했다. 이 환경의 결과로 하드웨어 GPU 성능이나 실기기 터치를 보증하지 않는다.

## 남은 출시 작업

- 39종 시설과 모든 구성원의 전문 아트 일관성·기능 실루엣에 대한 사용자 승인. 병원·은행은 상업 건물을 개조한 모델이며 켄타로스는 자체 하반신과 외부 상반신의 조합이다.

- 장기 인간 플레이의 재미·난이도·위기 빈도 조정과 GPU 메모리·프레임 목표 검증.
