# 확장 명세 2026-09-29 — 조사에서 찾은 빠진 항목의 반영

근거(확인일 2026-09-29): learntownstar.com 건물·생산·근접 효과·연못·벌통·양 우리·창고 페이지, iq.wiki/kr/wiki/town-star. 이 문서는 작업자 모두가 쓰는 정본 id 표다. id와 한글 이름을 바꾸지 않는다. 수치(가격·시간·비용·해금 단계)는 밸런스 담당이 정한다.

Town Star의 코드·그림·이름·수치는 쓰지 않는다. 사슬의 구조만 참고한다. NFT·P2E·토큰·주간 규칙·고용/임금 시스템은 넣지 않는다(지시 사항). 지게차·트랙터·일꾼 집·건축가 집도 같은 이유로 제외한다.

사슬(입력 → 출력, 참고용. 실제 조합·수량은 밸런스 담당이 정한다):
- 포도밭 → 붉은/흰 포도 → 와이너리(+오크통) → 적/백 포도주
- 사탕수수밭 → 사탕수수 → 제분소 대안 제품 → 설탕. 소금밭 → 소금
- 카카오 농장 → 카카오 → 초콜릿 공방(+설탕) → 초콜릿. 딸기밭 → 딸기 → 빵집 대안 → 딸기잼
- 박하밭 → 박하 → 제과점 대안 → 박하 사탕. 호박밭 → 호박 → 빵집 대안 호박 파이, 벽돌 가마 대안 호박등(+밀랍+털실)
- 참나무 농장 → 참나무 원목 → 제재소 대안 → 오크통, 나무 상자
- 양 우리 → 양모 → 방직소 대안 → 털실. 봉제소 대안 → 천 상자(나무 상자+작업복+밀랍 계열)
- 젖소 우리 → 우유 → 빵집 대안 → 버터. 양봉장(야생 클로버 필요) → 꿀·밀랍. 오리 집 → 오리알. 사료 공장(밀 → 사료)이 양·젖소·오리를 먹인다
- 모래 채굴장 → 모래 → 유리 공방 대안(모래 유리). 점토밭 → 점토 → 벽돌 가마 입력. 채석장 대안 → 석회암. 철광산 대안 → 크롬. 제철소 대안 → 청강(강철 사슬 최고가)
- 포장 공방: 식량 소포(꿀·잼·빵), 선물 소포(케이크·포도주·호박 파이). 소포는 최종 상품(`final`)

이미 있는 "한 시설이 여러 제품을 만드는" 장치(`recipes`)를 우선 쓴다. 그 장치로 안 되는 자원 조건(자연 바위·광물 타일)이 걸리면 새 시설로 나눈다.

건물은 1×1 타일 한 칸이다. 연못·목초지·야생 클로버는 지형을 바꾸는 시설이며 건설 조건과 철거 방식을 시설 카드에 분명히 적는다.

## 3. 새 규칙 5가지

1. **산이 그늘·바람막이를 만든다** — 산 타일이 주변에 그늘과 바람막이(최대 5칸)를 준다. 지금은 건물만 만든다.
2. **같은 종류 시설이 붙으면 빨라진다** — 같은 종류 시설이 맞닿으면 생산 시간이 줄어든다(최대 50%). 상한과 대각선 포함 여부를 정하고 시설 창에 보여 준다.
3. **소금기** — 바다에 닿은 칸 근처는 소금기가 생겨 관개 작물이 느려지고 소금밭은 빨라진다.
4. **광산 침수** — 담수·바다 옆 광산(철광산·탄광·구리 광산·모래 채굴장)은 느려진다.
5. **물 효과 계단식 + 작물 물 요구량** — 물 효과를 있음/없음이 아니라 가까운 칸 2·다음 칸 1로 계산한다. 연못이 이 값을 준다. 작물마다 물 요구량이 다르다(iq.wiki 기준 밀 3·소금 3·목화 4·나무 7·사탕수수 8). 요구량을 채우면 물 운반이 생략된다.

기존 저장은 새 규칙 없이 예전 규칙을 유지하거나 명시적으로 이전한다(`land.ecology`가 없는 저장의 처리 방식을 따른다). 새 자원은 기존 저장에서 0으로 시작하고 읽기가 깨지지 않아야 한다.

## 4. 그림

이미지 생성 도구가 없어 스크립트로 그린 픽셀 그림을 쓴다. 기존 82종의 화풍(단순화·1×1 정방형·네 방향 SE→NE→NW→SW·192×768 아틀라스)을 따른다. 이미지 모델로 다시 그려야 할 후보는 `docs/PIXEL_ART_AUDIT.md`에 정직하게 적는다.
