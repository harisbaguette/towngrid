# 타운스타 비교 보완 체크리스트

- [x] **자유로운 시작** — 첫 건물을 직접 선택한다. 초반 안내는 설정에서 켤 수 있다.
- [x] **시작 수출 수단과 미니 창고** — 시작 부지에 운송 수단·연료 40개·미니 창고 160칸을 제공한다. 일반 창고 없이도 생산물 운반과 판매를 시작한다.
- [x] **주민 표시** — 집에서 나온 실제 주민을 표시하고 시설마다 장식 일꾼을 자동으로 늘리지 않는다.
- [x] **건물 개선** — 생산·창고·주택·운송 시설의 개선 효과와 비용을 실제 운영에 반영한다. 생산 시설은 원료·전력 수요도 함께 늘어난다.
- [x] **주택 철거 후 저장** — 짐을 반환하는 주민을 저장·복원한다. 주민 수가 많은 마을의 파일 내보내기도 가능하다.
- [x] **겹치는 발전 반경** — 공장이 닿는 발전망 사이에서 전력을 나눠 공급한다. 우선순위와 전체 필요량을 지키며 건물 목록 순서에 의존하지 않는다.
- [x] **배터리** — 시설별 충전량을 사용한다. 연결망에 남는 전력이 있어야 충전하며, 이전·중지·파손 중인 시설은 작동하지 않는다.
- [x] **보관 병목 안내** — 입고 거부·수용 상한·예약 공간·전용 보관소·만재·경로 문제를 구별하고 보관 설정으로 연결한다.
- [x] **분할 납품 안내** — 이번 운송분을 보낼 수 없는 연료·차량·경로 문제를 표시한다.
- [x] **외교 주문의 목적지** — 주문한 신생국 수도까지의 경로로 거리·운송 시간·연료를 계산한다.
- [x] **분리 정유 공정** — 정유소에서 석유 중간재를 만들고, 우물의 공업용수와 혼합해 연료를 만든다. 중간재를 비축·운반하고 정유소끼리 분업할 수 있다. 기존 일괄 공정도 선택 가능하다. 소형 증류소는 연료가 5개 미만일 때만 쓰는 손실성 비상 설비다.
- [x] **주간 산업 도전** — 매주 월요일 한국 시간 09시에 부지·목표·점수 규칙이 바뀐다. 같은 회차는 같은 조건이며 저장·재도전에도 유지된다. 기록은 현재 브라우저에 보관한다.
- [x] **부재 중 생산** — 설정에서 켜면 진행 중 자리를 비운 시간을 최대 10분, 1배속으로 반영한다. 연료 부족·적자·사건에서 멈추고 복귀 후에는 일시정지한다. 수동 일시정지와 산업 도전에는 적용하지 않는다.
- [x] **전력 배치 안내** — 지도 도구의 전력망 색상과 건설·개선 후 예상 수요를 함께 표시한다.
- [x] **초보 운영 안내** — 운반 부족에 주택 개선·손수레를 제안하고 왕복 거리에 맞춘 연료 수입량을 표시한다. 원료 고갈·비효율 배치·납품용 재고 부족의 해결 행동도 제공한다.
- [x] **복귀 중 창 전환** — 부재 계산을 중복 실행하지 않는다. 계산 중 다시 창을 숨기면 안전하게 멈추며, 자동 저장과 화면 전환이 계산이나 일시정지 상태를 덮어쓰지 않는다.
- [x] **손상된 도전 기록** — 잘못된 최고 점수·납품량을 건너뛰고 정상 기록을 표시한다. 기록 저장 공간이 부족해도 게임 저장 결과와 구별해 알린다.
- [x] **생산법 변경 후 보관 안내** — 변경 전 완성품과 반환 재료 중 실제로 막힌 품목·보관 장소를 안내한다.

- [x] **다음 행동 노출** — 지도에서 첫 건설·생산 막힘·승급·납품으로 바로 이동한다.
- [x] **도전 다양화** — 9개 생산 사슬과 시간·연료·시설 수 조건을 순환한다. 기존 회차 저장은 이전 규칙으로 복원한다.
- [x] **독립된 상대 경제** — 컴퓨터 상회가 자신의 시설·원료·운영비·연료·출하 한도로 점수를 얻는다. 타일 배치와 주민 경로는 축약한다.
- [x] **판매 대금과 별 분리** — 계절 가격과 별 품평회를 서로 다른 일정·품목·배수로 적용한다.
- [x] **온라인 기능** — 계정·복구 코드·서버 저장·개인 및 상회 순위·플레이 재실행 검증을 제공한다. [연결과 운영](ONLINE.md)을 참고한다.
- [ ] **공개 운영 서버** — 인터넷 서버와 HTTPS 경로 연결은 아직 설정되지 않았다. 로컬 서버 실행만으로 외부 접속을 제공하지 않는다.
- [ ] **첫 1시간 사람 점검** — 처음 보는 사람 5명 중 4명의 8단계 도달 여부는 아직 확인하지 못했다. [점검 방법](PLAYTEST.md)과 게임 내 기록을 사용한다.
- [ ] **실제 모바일·장기 운영** — 실기기 발열·메모리·터치와 장기간의 공개 서버 운영은 추가 확인이 필요하다.

캠페인의 주간 순위는 컴퓨터 상회와 비교한다. **온라인·서버 저장**의 순위는 같은 서버에 기록을 제출한 사람끼리 비교한다. 상회는 점수 합산 방식이며 같은 마을을 동시 조작하지 않는다. 재실행 검증은 점수·자금 조작을 걸러내지만 자동 플레이·다중 계정까지 탐지하지는 않는다.

## 비교 자료의 범위

- [Gala 공식 시작 안내, 2024-09-05](https://news.gala.com/common-ground-world/getting-started/): 초기 연료 40개, 가공품 판매와 유지비, 배치 효과, 캐주얼·주간 대회 모드. 주간 대회의 목표 품목과 생태 지형 조합이 달라진다고 설명한다.
- [Gala 공식 Harvest Pie Hoedown, 2024-07-15](https://news.gala.com/common-ground-world/common-ground-world-harvest-pie-hoedown/): 판매 대금과 별 점수의 별도 조정, 목표 품목·지형 지정, 재접속 시 오프라인 진행을 따라잡는 기능.
- [Learn Town Star 연료 생산 안내, 2021-12-18](https://learntownstar.com/beginners-guide/how-to-make-gasoline/town-star-gasoline-production-guide/): 원유→석유 중간재→가솔린, Water Drum·Energy 운반과 보관. 과거 사슬 구조를 비교하는 자료이며 현재 가격표로 사용하지 않는다.
- [Gala 저장 연결 개선 안내, 2025-09-26](https://news.gala.com/gala-games/townstar-improved-disconnection-flow/): 연결이 끊어진 채 저장되지 않는 진행을 계속하는 문제를 다룬다. 타운그리드에서는 서버 연결보다 로컬 저장 실패 후의 복구 동작이 점검 대상이다.
