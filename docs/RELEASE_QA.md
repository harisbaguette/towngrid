# 오르베타른 검증 기록 — 2026-09-25

## 수정 사항

- 자동 복구와 새 게임 전 백업 분리. 손상된 저장이 정상 백업을 대체하지 않음.
- 신생 국가·정치 관계·주민 작업·시설 레벨·적 경로·운송 시간의 중첩 저장 검사. 비정상 과거 날짜로 장시간 루프에 빠지는 파일 거부.
- 소리 48개 동시 재생 상한, 채널 게인 및 압축기, 종료 시 연결 해제. 일시정지·음소거·탭 비활성 시 재생 정리. 잡음 버퍼 재사용.
- OGG/MP3 대체 디코딩, 누락 음원 재시도, 설정에서 음악/효과음/환경음 듣기.
- 품질 설정, 인스턴스 GPU 버퍼 해제, 배경 재사용, CPU 주민 자세 캐시 상한 및 정지 장면 재사용.
- 모달·불러오기 중 입력과 시간 보호, 버튼/입력창의 단축키 중복 방지, 터치 긴 누르기 오건설 방지.
- 320/390 세로 화면과 844×390 가로 화면의 자원 표시·도구·카메라·건설 도크·설정 닫기 배치 보완.
- 신생 국가 재분열 이름 길이 억제. 켄타로스 신체 연결·가방·네 다리 보행 보완.

## 실제 브라우저에서 확인

Chrome, 1363×936 데스크톱 및 동일 게임을 담은 320×740 / 390×844 / 844×390 프레임을 사용했다.

- 시작 국가와 인족/엘프족 선택, 켄타로스 미리보기, 산업도시 시연, 주민 목록을 열었다.
- 390픽셀 화면에서 빈 땅에 창고를 놓고 비용 차감과 시설 패널을 확인했다.
- 회전·확대 버튼, 설정, 세계 지도, 거점 이동을 조작했다.
- 효과음 23/23개가 running 상태에서 디코딩됐다. 음악 시험 후 활성 소리 4개, 종료 후 0개. 메뉴를 연 동안 게임 시각 1.2초가 유지됐다.
- 양 거점을 여섯 차례 왕복했을 때 CPU 캐시는 75→42→69→42→69→42개였다. 이는 CPU 캐시의 제한된 검증이며 GPU 메모리 측정이 아니다.
- 390픽셀 화면에서 좌/우 도구 하단은 646px, 건설 도크 상단은 656px로 10px 간격을 확인했다.
- 844픽셀 가로 화면에서 건설 도크 x=62~782, 카메라 x=792~834로 겹치지 않는다.
- 실제 브라우저의 내보내기 데이터(58,949바이트)를 디코딩하고 다시 파일 불러오기로 넣었다. 23단계/2거점/32개 시설/17,994G를 유지하고 일시정지 상태로 복원됐다.
- 동일 페이지를 다시 열고 계속하기로 저장 상태 복원을 확인했다.
- 습격 예고와 오크/마족 3명 상태를 화면에서 확인했다. 방어 버튼의 비용·효과는 자동 시험에서 검증했으며 해당 클릭의 브라우저 완료 증거는 확보하지 못했다.

## 아직 정식 출시 승인으로 볼 수 없는 부분

1. 이 환경은 WebGL 없이 CPU 렌더러를 사용했다. 산업도시에서 대략 8~14 FPS 관측, 정지 상태에서는 30 FPS 갱신. 저사양 목표 성능을 만족했다고 표시하지 않는다.
2. 실제 iOS/Android 터치, 하드웨어 GPU의 장시간 메모리, Safari/Firefox 재생과 실제 청감은 확인하지 못했다.
3. 다운로드 완료 이벤트가 이 브라우저에서 오지 않았다. 저장 데이터 생성/파싱/파일 불러오기는 확인했지만 파일 다운로드 완료는 미확인이다. 텍스트 보관 경로를 추가했다.
4. 켄타로스 전용 원본과 시설 36종·모든 종족의 통일된 최종 아트 승인, 외부 신규 이용자의 재미·난이도 평가가 남았다.
