# 타운그리드 음악

배경음악은 총 51곡이다. 화면·상황별 29곡, 국가별 14곡, 지형별 8곡을 사용한다. 같은 지형의 여러 부지는 지역곡을 공유한다.

## 재생과 조절

- 대기 화면부터 음악을 재생한다. 브라우저가 자동 재생을 막으면 **소리 켜기**를 누르거나 화면을 한 번 조작한다. 별도의 계정 로그인 화면은 현재 없다.
- 대륙 전체는 탐험곡, 국가 단위로 확대하면 해당 국가곡을 재생한다. 부지에 가까이 가면 지형곡과 국가곡이 번갈아 나온다. 산업 시설이 발달한 마을은 산업곡도 이어진다.
- 다른 지형에 들어가면 지형곡, 같은 지형에서 국경을 넘으면 새 국가곡부터 시작한다. 음악의 기준은 카메라가 보는 위치다. 무주지에는 별도 주제곡이 있고 신생 국가는 기원 국가의 곡을 사용한다.
- 지도 이동은 같은 지역에 약 1초 머문 뒤 음악을 바꾼다. 메뉴·관리 창·건설·시설 정보는 1.25초 이상 머물면 전용곡으로 바꾼다. 습격·로딩·복구는 바로 전환한다. 두 곡을 잠깐 겹쳐 연결하며 창을 닫으면 기존 곡의 듣던 부분으로 돌아간다.
- 짧은 화면 전환에는 전환 효과음이 나온다. 파일을 기다리는 로딩 화면에는 로딩곡이 나온다.
- 설정에서 전체·음악·효과음·환경음의 음량을 조절하고, 현재 곡을 확인한다. 음소거와 음량은 브라우저에 저장된다. 다른 탭에서는 소리를 멈춘다.
- 읽지 못한 곡은 마을 음악으로 대체한다. 설정의 소리 재시도는 효과음과 실패한 배경음악·환경음을 다시 불러온다.
- 새와 곤충 소리는 화면의 낮밤 주기를 따른다. 사막·설원·화산에는 숲의 생물 소리를 쓰지 않는다. 폭풍 소리는 발생한 마을 주변에서만 나오며 설원에서는 빗소리 대신 바람이 강해진다.
- 산업 도전 성공과 시간 종료에는 결과 효과음이 한 번 나온다. 승급·습격 등 주요 알림이 들리는 동안 배경음악을 잠시 낮춘다.
- 모든 곡은 −20 LUFS를 기준으로 음량을 맞춘다. 타이틀은 피아노·플루트, 홈과 평야는 경쾌한 합주, 세계 지도는 관현악 탐험곡을 사용한다.
- 시설·지형·캐릭터 등 독립 미리보기와 UI 비교 화면에도 소리가 있다. 상단 **소리**에서 게임과 공유하는 음소거·음량을 조절한다. 여러 대상을 비교할 때 화면에 보이는 대상 하나의 효과음을 재생하며, 캐릭터는 선택한 인물의 동작을 따른다. 동작을 멈추면 작업·발걸음 효과음도 멈춘다.

## 원본과 재생 파일 관리

곡 배정은 `src/app/game/soundscape.js`, 카메라 위치 판정은 `audio-geography.js`, 재생·교차 전환·듣던 위치 기억은 `audio.js`에서 관리한다. 원본은 `art-source/audio/bright-town/`와 `art-source/audio/world-score/`에 있다. 실행용 OGG/MP3와 곡별 출처·허가·해시는 `public/assets/audio/`에 있다.

`python scripts/fetch-world-score.py`는 국가·지역·화면 음악 원본을 복구한다. `python scripts/pack-town-music.py`는 원본 해시를 확인하고 두 차례 측정으로 −20 LUFS·−2 dBTP 음량 보정과 OGG/MP3 변환을 수행한다. 습지곡 끝의 긴 무음은 정본의 `trim_end_seconds`에 따라 잘라 곡 사이의 공백을 없앤다. 이때 `music-sources.json`과 게임의 곡 정보 `music-catalog.js`도 갱신한다. 변환에는 FFmpeg와 NumPy가 필요하다.

시작할 때 모든 음악을 내려받지 않는다. 현재 곡·다음 곡·교차 재생 중인 곡만 디코딩한 채 유지한다. 게임 저장 형식에 음악 상태를 추가하지 않는다.

## 연결 확인

- `node tests/music-routing.mjs`: 화면 누락, 국가·지형 전수 배정, 곡 중복, 파일 해시, 영토 소유권 판정.
- `node tests/release.mjs`: 교차 재생 수, 재생 위치 복귀, 다운로드 실패·재시도, 음소거와 정리.
- `node tests/preview-audio.mjs`: 동작 주기·정지·부유 캐릭터와 알림 중 음량 복귀.
- `python tests/music-mastering.py`: OGG/MP3 전체의 체감 음량과 실제 피크. FFmpeg가 필요하다.
- 실행 중인 개발 서버에서 `tests/title-audio-browser.mjs`, `tests/soundscape-browser.mjs`, `tests/world-music-browser.mjs`, `tests/preview-audio-browser.mjs`를 Playwright로 실행한다. 이 스크립트들은 실제 브라우저 재생 신호와 화면 조작을 확인한다. 곡의 분위기가 취향에 맞는지는 직접 들어 보고 판단해야 한다.
