# 연속 월드

국가 선택, 부지 선택, 시작 전 미리보기, 플레이는 `GameScene`의 같은 캔버스와 카메라를 사용한다. `세계`는 대륙으로 축소하며 집 버튼은 현재 운영 중인 땅으로 돌아온다. 다른 부지를 누르면 가까이 보기와 실제 확보 조건이 열린다. 거점 운영을 바꿔도 같은 월드 위치로 이동한다.

## 좌표와 지형

세계는 50×31개 부지 칸, 부지 하나는 24×24 타일이다. `world-space.js`의 월드 좌표는 타일 단위이며 `(cellX×24+localX, cellZ×24+localZ)`로 변환한다. 정치·무역 자료의 기존 26px 좌표와 혼용하지 않는다. 카메라와 건설 좌표는 운영 중인 거점을 원점으로 두고 `WorldLandscape`를 반대 방향으로 옮긴다.

`terrain-tiles.js`가 시뮬레이션과 미개발지의 타일을 생성한다. `WorldTerrainData`는 보유 거점의 실제 타일을 먼저 읽고, 나머지는 같은 생성기와 `world-grid.js`의 이웃 지형을 읽는다. 새 부지를 확보할 때 seed는 0으로 고정하고 진입 도로만 개간한다. 기존 저장의 seed·land·시설·자원은 해당 시뮬레이션에서 읽는다.

## 렌더링

`world-ground.js`는 같은 월드 좌표를 사용해 먼 지면과 가까운 지면을 그린다. `world-landscape.js`는 카메라 주변 상세 지면을 최대 25개 부지만 유지하고, 미개발지 타일 캐시는 64개로 제한한다. 부지 크기·물길·지명 위치는 확대 수준에 따라 바뀌지 않는다. 먼 나무의 수와 지면 해상도만 줄인다.

안개는 카메라 중심에서의 거리와 화면 범위를 따른다. 소유 경계는 안개의 기준이 아니다. 세계 바깥의 비선택 지면은 안개 색으로 이어진다. WebGL과 Canvas 대체 렌더러가 같은 타일과 부지 캐시를 사용한다.

`FogLayer`는 지면 가까이 흐르는 옅은 안개, `CloudLayer`는 기존 픽셀 원화 4종의 구름을 그린다. `WorldAtmosphere`가 두 컴포넌트를 시작 지도·플레이·지형 미리보기에 연결한다. 월드 좌표를 따라 이동하고 확대 수준 사이에서는 서로 다른 크기의 구름층이 서서히 교체된다. 화면 중심은 옅게, 건설 중에는 전체 농도를 낮춘다. 동작 줄이기 설정은 흐름을 멈춘다. 효과는 저장·생산·선택 판정에 관여하지 않으며 안개 22개·구름 14개 이내로 표시한다. Canvas와 낮은 품질에서는 개수를 줄인다.

비·눈·바람·수면·새·작업 입자·차량 먼지·시설 변화·마력·낮밤은 `WorldEffects`가 실제 지형과 상태를 읽어 표시한다. 조건과 미리보기는 [환경·효과 컴포넌트](WORLD_EFFECTS.md)를 참고한다.

`WorldViewControls.tsx`는 국가·거점 이름과 카메라 버튼, `WorldPlotPanel.tsx`는 부지 선택과 확보를 맡는다. `CampaignWorld.tsx`의 부지 찾기는 같은 월드 카메라를 이동시킨다. `WorldAtlas.tsx`와 기존 아틀라스 패킹 파일은 비교·지형 도구용이며 메인 게임의 지도 화면에는 사용하지 않는다.

## 확인 명령과 한계

`node tests/seamless-world.mjs`는 좌표, 실제 지형, 부지 확보, 저장 호환, 캐시 상한을 검사한다. 실행 중인 개발 서버에서 `node tests/seamless-world-browser.mjs <playwright/index.mjs> <chrome.exe>`로 시작 흐름·회전·선택·건설·거점 전환·모바일·Canvas를 확인한다.

미개발지에 생산 시뮬레이션을 새로 생성하지 않는다. 보유 거점만 기존 캠페인 규칙으로 생산한다. 먼 지형은 간략하게 표현하며, 기존 격자 수역의 직선 형태와 지형 전환은 남아 있다. Canvas의 안개는 화면에 합성하므로 WebGL의 거리 안개와 픽셀이 같지는 않다.
