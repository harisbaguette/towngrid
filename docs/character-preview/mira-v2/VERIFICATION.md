# 미라 1명 시안 검증

2026-09-27 / Windows / Node v22.18.0 / Chrome headless.

- 원본 3개 복사 및 48개 프레임 좌표·발 기준점 범위 검사 통과.
- Chrome에서 6개 동작 선택, 각각 8개 프레임 직접 선택, 재생/정지 확인.
- 같은 포즈를 표시하는 두 화면 갱신 사이에도 이동 좌표가 증가함을 확인. 포즈 프레임 변경에 위치 이동을 묶지 않았다.
- HTTP와 서버 없는 `file:` 열기 모두 확인. 페이지 오류와 400 이상 이미지/문서 응답 없음.
- 1440px 데스크톱과 390px 모바일 스크린샷 확인. 가로 넘침 없음.
- `npm run typecheck`, `npm test` 통과. 기존 게임의 저장·물류·캠페인 및 24종 자산 회귀 검사 포함.
- `npm run build` 통과. 기존 큰 JS 청크와 Vinext 경로 분류 안내, 플러그인 소요 시간 안내는 남아 있다. 외부 배포는 수행하지 않았다.

`browser-check.json`은 브라우저 확인 결과다. 이미지들은 실제 미리보기 화면 캡처다. 이 검사는 화풍 승인이나 전체 동작의 완성을 뜻하지 않는다. 현재 시안의 미완성 범위는 원본 폴더 README와 미리보기 하단에 명시했다.
