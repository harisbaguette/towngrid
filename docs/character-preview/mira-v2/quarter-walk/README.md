## 이동 수정의 측정

기존 코드는 한 경로 지점에 도달하면 남은 시간의 이동량을 버렸고, `.01` 이내에서 미리 다음 지점으로 넘어갔다. 새 코드는 남은 이동량을 다음 구간까지 소비하며 정확한 경로 꼭짓점을 지난다. 각 구간의 진입 가능 여부도 검사한다.

같은 직각 경로, 속도 2.37칸/초, 10초의 결정적 비교 (`node tests/character-movement.mjs`):

| 초당 실행 횟수 | 기존 이동 거리 | 수정 후 | 예정 거리 |
| --- | ---: | ---: | ---: |
| 20 | 22.237000 | 23.700000 | 23.7 |
| 30 | 23.079000 | 23.700000 | 23.7 |
| 60 | 23.079000 | 23.700000 | 23.7 |
| 144 | 23.608958 | 23.700000 | 23.7 |

게임 보행은 실제 누적 경로 거리로 진행한다. 속도만 바꾸거나 카메라를 돌렸을 때 위상이 건너뛰지 않는 것을 검사했다. 경제 속도 상수와 저장 스키마는 변경하지 않았다. 이동량 검증이며 기기별 FPS 향상 측정은 아니다.

## 아트 판정

미승인 시안이다. 네 방향 걷기는 이미지 생성 후 한 번 수정 요청했지만 반대쪽 발이 앞으로 나오는 접지 포즈가 여전히 충분히 구분되지 않는다. 대기·작업·인사·상자는 이전 E 방향 시안이다. 원화의 크림 배경·체형 차이와 전용 전투 작화도 남아 있다. 전체 화풍·부드러운 애니메이션 완성이나 게임 적용 완료로 판정하지 않는다.

원본/프롬프트/앵커 명세는 `art-source/pixel-characters/prototypes/mira-v2/`에서 관리하며 `node scripts/pack-mira-preview.mjs`로 실행용을 갱신한다.
