# 2026-09-26 플레이 화면 개편

## 원인

기능을 추가하는 동안 건설 목록과 운영 카드가 상시 노출됐다. 리본·격자·제본 장식을 기본 HUD까지 확장해 마을의 생산 흐름보다 메뉴가 먼저 보였다. 기본 시점은 확대되어 있었고 지형·도로·물의 대비도 약했다.

## 변경

- 기본 화면: 마을 전체, 좌측 자원, 우측 승급/현재 계약, 모서리의 건설·시장·세계 지도.
- 건설: 버튼으로 열고 선택 후 닫힘. 빈 타일을 먼저 골라 해당 위치에 건설하는 흐름 추가.
- 건물: 생산 재료·완성품·진행도·가동 전환을 작은 카드로 표시. 효율·개선·특화는 펼쳐서 확인.
- 장식: 기본 HUD와 주요 대화창의 리본·종이 격자·제본·차양 제거. 기존 청색/크림색 계열은 유지.
- 지도: 기본 시점과 표시 범위 조정. 잔디·도로·수역 대비 강화. 주변 나무 크기 조정.
- 렌더링: CPU 대체 렌더의 지면 옆면 방향/내부 면을 바로잡아 해안 톱니 제거.
- 조작: B로 건설 목록, Esc로 선택·배치 취소. 버튼에 포커스가 남아도 동작.
- 유지: 판타지 종족/국가, 1타일 시설, 33단계 승급, 생산/물류, 확장/세계 지도, 저장 데이터.
