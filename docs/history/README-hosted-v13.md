# 오르베타른 · ORVETHARN

Town Star에서 좋아했던 건설·생산·운반·판매 흐름을 중심으로 만든 판타지 + 현대 산업 경영 프로토타입. React / Vinext / Three.js. WebGL이 없는 환경에는 같은 모델을 그리는 Canvas 렌더러가 있습니다.

## 이번 기준

- 건물의 점유 면적은 모두 **1타일**. 지역 맵은 24×24칸이며 처음에는 8×8칸만 사용할 수 있습니다. 맵 안에서 4×4구역을 확보하고 다른 지역에 별도 거점을 엽니다.
- 농노부터 패권국까지 **33단계**. 생산 실적·납품·채무·가족 구출·운송망·자치권·외교 지지·방위력에 따른 승급 조건이 있습니다.
- 세계 지도에는 3개 대륙과 30개 국가가 있습니다. 인족·엘프족 국가 12곳은 시작 지역, 나머지 18곳은 적대 세력입니다. 패권국 영향권부터 독립 왕국/연방, 일반 국가, 종속 공국, 수도직할령, 영지, 개척지와 개인 신분까지 표시합니다.
- 플레이 진영은 인족(인간·드워프·티탄)과 엘프족(엘프·정령·켄타로스·요정). 마족·오크족·수인족 계열은 현재 공격 세력입니다.
- 모든 플레이 계열은 같은 현대·마법 산업을 이용합니다. 종족 특화는 시설의 선택형 운영 방식이며 별도 투자와 유지비가 있습니다. 국가 정책과 타일의 비옥도·수분·광물·마력은 서로 다른 요소입니다.
- 주민은 생산 시설이 늘면 자동 합류합니다. 별도 채용·임금 협상·고용 목표는 없습니다. 운반 경로는 실제 빈 칸과 도로를 사용합니다.

## 산업과 확장

밀·빵 생산에서 제철, 정유, 합성 소재, 전자 회로, 자동차, 의약품으로 이어집니다. 증기 기계공장, 마력 발전소, 방어 결계를 만드는 마탑, 운송을 가속하는 마력 중계소가 현대 공장과 함께 작동합니다.

거점별 창고 재고는 분리되어 있습니다. 자금과 회사의 성장 실적은 공유합니다. 트럭 또는 철도 노선을 개설하면 출발 시 자원과 운송비가 차감되고 이동 시간이 지난 뒤 도착 창고에 들어갑니다. 양쪽 화물역에는 선로와 전력이 필요합니다. 국내 트럭 48초, 철도 24초이며 해외는 12초 추가됩니다. 연료를 직접 생산하면 외부 운송사 연료 비용을 줄일 수 있습니다.

폭풍·질병·파업·습격·마력 폭풍·무역 압박이 생산망에 영향을 줍니다. 병원·축전 시설·마탑·경비대·복지 협약으로 대응합니다. 마족은 동력망을 교란하고 수인족은 화물 운송을 지연시킵니다. 투자 배당과 외교 지지, 지역 자치권 협약도 사용할 수 있습니다.

다른 국가의 산업·자금·불만도는 일일 단위로 움직입니다. 불안정한 국가에서 신생 국가가 생깁니다. 플레이어의 자치 지역도 불만이 높아지면 독립할 수 있습니다. 사업장을 곧바로 삭제하지 않고 현지 세금이 다시 부과됩니다.

## 경제와 대응

자동 판매는 생산 원료 두 회분, 현재 계약, 출발 노선의 화물, 사용자가 지정한 최소 재고를 보호합니다. 해금한 제품은 시세의 1.85배를 기준으로 수입할 수 있지만 생산 실적으로 인정하지 않습니다. 조림은 15G와 물 2개를 쓰며 160초 이후 다음 일일 갱신에 나무로 성장합니다. 자금이 150G 이하라면 5일마다 보유액 500G까지 회복할 수 있고 지급액의 130%가 빚에 추가됩니다.

습격은 경고 후 적이 실제 통로를 따라 창고로 접근합니다. 경계 강화는 80G와 밀 6개가 들며, 경비대와 마탑은 적의 체력을 줄입니다. 도착한 적은 주기적으로 피해를 주고 55초 후 철수합니다. 폐쇄한 운송 노선은 출발한 화물을 먼저 인도합니다.

신생 국가는 산업·불만·자금이 변하며 실제 물품 교역, 민생 지원, 방위 협정, 독립 지지 요청의 대상이 됩니다. 불안정한 신생 국가에서도 다시 나라가 분리됩니다. 방위 협정은 상대국 불만을 낮춰 분열을 억제하는 현재 구현이며, 동맹군이 전장에서 지원하는 시스템까지 구현한 것은 아닙니다.

## 조작과 저장

드래그 이동 / 휠 확대 / 우클릭 드래그 또는 Q·E 회전 / Space 일시정지. 모바일은 한 손가락 이동, 두 손가락 확대, 회전 버튼, 같은 타일을 다시 눌러 건설합니다.

설정에서 음악·환경음·효과음·전체 음량을 각각 조절합니다. 기존 `first-land-v1` 키를 유지하며 이전 저장을 새 규격으로 이전합니다. 새 게임은 확인 후 이전 저장을 백업합니다. JSON 파일 내보내기·불러오기와 이전 백업 복구를 지원합니다. 저장 용량 초과와 잘못된 파일은 오류로 표시합니다. 산업도시 둘러보기는 일반 저장을 덮어쓰지 않습니다. 캠페인은 이 브라우저에 저장되며 다른 기기와 동기화되지 않습니다.

## 에셋

Kenney Fantasy Town Kit, City Kit Industrial, Car Kit, Train Kit, RPG Audio 및 Quaternius Animated Characters / Textured Cute Monster Pack을 사용합니다. 모두 CC0. 출처는 `public/assets/ATTRIBUTION.md`와 각 라이선스 기록에 있습니다.

티탄은 Shyr Games의 CC0 Stan the Golem 애니메이션 모델을 사용합니다. 늑대·여우·용·박쥐·가오리는 Quaternius의 CC0 리깅 모델을 추가했습니다. 켄타로스는 적절한 무료 애니메이션 모델을 확보하지 못해 기존 인체 리그와 프로젝트의 말 몸체를 조합한 임시 에셋입니다. 요정의 날개와 문화 장식, 기능을 보여주는 일부 기계 장치 및 애니메이션은 프로젝트에서 보완했습니다. 전문 제작된 종족별 완성 아트 세트는 아닙니다.

## 구현 범위와 검증

플레이 가능한 프로토타입입니다. 국가 AI와 외교·독립은 간단한 수치 시뮬레이션이며 전술 전투, 전쟁 전선, 세밀한 국경 변경은 구현하지 않았습니다. 플레이어가 사용할 수 있는 건설·생산·수입·판매·외교 행동만 수행하는 자동 시험에서 33단계를 완주했습니다. 게임 내 59일, 거점 7곳, 자동차 80대 생산을 확인했습니다. 이는 진행 가능성 검증이며 사람의 장기 플레이로 재미와 난이도를 검증한 결과는 아닙니다. 동일한 대륙 모양 복제를 피하도록 세계 지도 지형을 나누었지만 지도는 아직 정치 선택용 개략도입니다.

- `node tests/simulation.mjs`: 실제 운반·식품 생산·수익·저장·부지 확장·폭풍·부채·전력.
- `node tests/fantasy.mjs`: 타일/국가 효과·진영 구성·실제 생산으로 초반 승급·납품 예약·화물 보존·애니메이션/사운드 파일.
- `node tests/campaign.mjs`: 1타일 규격·7계열 공통 첨단 생산·적대 진영 잠금·지연 운송·운송 중 저장·거점 재고 보존·자동 주민·특화·신생 국가.
- `node tests/quality.mjs`: 10개 오류 상황 묶음. 재고 보호·유료 수입·회생·조림·의료·축전지·습격·노선 폐쇄·신생국 외교·손상 저장·에셋 연결.
- `node tests/full-campaign.mjs`: 빈 땅부터 33단계까지 실적을 획득하고 중간 저장을 복구하는 자동 완주.
- `node node_modules/typescript/bin/tsc --noEmit`.

이번 수정본은 브라우저 연결 실패로 새 화면·실제 터치·청음·GPU 메모리를 검증하지 못했습니다. `docs/QUALITY_CHECKLIST.md`에 완료와 미확인을 구분합니다. `docs/playtest.jpg`는 이전 버전의 자료이며 이번 변경의 화면 증거가 아닙니다.

기존 Sites 프로젝트의 주소와 비공개 범위를 유지합니다.
