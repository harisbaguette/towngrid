# 건물·운송·환경 동작 검증 — 2026-09-29

홈의 **체험·점검 → 일러스트 테스트**(`/art-preview.html`)에서 이동·적재·항구 상하차·손상·복구를 네 방향으로 비교한다. **CPU 표시**로 같은 장면을 소프트웨어 렌더러에서도 볼 수 있다. 저장하지 않는다.

## 반영한 내용

- 운송 10종에 동작 아틀라스를 연결했다. 말 다리, 바퀴와 외륜, 노, 프로펠러가 움직이며 물 위에서는 이동 중 물결을 남긴다. 실제 이동 거리로 프레임이 바뀌고 카메라 회전과 일시정지는 프레임을 진행시키지 않는다.
- 바다 연안항·강 항구·극지 항의 본체와 인양 화물을 분리했다. 실제 출고·입고 차량이 해당 터미널에 도착할 때만 움직인다. 운송 도중 다음 무역로를 바꾸어도 현재 차량의 실제 도착지를 따른다.
- 관과 컨베이어는 실제 재고 이동이 일어난 경로에 상품을 표시한다. 끊긴 경로·철거·운영 중지는 잔여 표시를 지운다. 표시 이벤트는 `WeakMap`에만 있으며 저장 데이터와 재고를 추가로 변경하지 않는다.
- 건물 104종은 자신의 본체를 나눠 심한 파손·붕괴를 표시한다. 기초를 타일에 고정하고 상부를 낮추며 수리 후 1.2초 동안 복구한다. 화면 재구성 뒤에도 수리 직전 체력을 이어받는다. 정상 건물은 파손용 조각을 만들지 않는다.
- 수차 등 회전 부품은 자체 평면에서 돌린 뒤 쿼터뷰로 투영한다. 회전할 때 타원의 축이 흔들리는 표시를 수정했다.
- 별도로 추가된 시설·상품·일상 그림과 통합해 건물 104종, 상품/지원 아이콘 77종, 일상 24장과 전환 4장의 연결 및 파일 누락을 검사했다.

## 표현 범위

운송 동작은 기존 원화 부품의 변형이며 프레임별 손작화가 아니다. 파손은 건물별 원본 실루엣의 변형과 공통 균열·잔해를 합성한다. 건물마다 새 폐허 원화를 제작한 것은 아니다. 극지 항의 북서 화물은 지붕에 가려져 정지하며, 가려진 부품을 건물 위로 드러내지 않는다. 계류 항공기는 실제 게임에서도 정지한다.

확장 시설 22종과 새 상품 35종은 별도 작업의 스크립트 작화이며 기존 원화와 세부 밀도 차이가 남는다. 해당 작화의 한계는 [전체 아트 현황](../../PIXEL_ART_AUDIT.md)을 참고한다. 이 검사는 저사양 실기기의 성능이나 모든 미술 요소의 완성을 보장하지 않는다.
