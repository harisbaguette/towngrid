# Town Star 참고 규칙과 타운그리드

Town Star의 시작 물류·연료·보관·운반을 참고한다. 아래 자료의 연도별 가격을 현재 라이브 수치로 취급하지 않으며, 타운그리드의 비용과 용량은 자체 설계다.

## 참고 자료

- [Gala 공식 시작 안내](https://news.gala.com/common-ground-world/getting-started/)는 초기 가솔린 40개, 생산을 통한 연료 자급, 묶음 판매, 창고 용량, 일이 없을 때 귀가하는 주민을 설명한다.
- [Learn Town Star — 초기 경제와 가솔린](https://learntownstar.com/beginners-guide/how-to-make-gasoline/how-to-build-an-economy-in-town-star-for-gasoline-production/)은 초기 운송 거점·연료 저장소, 추가 창고, 운반 거리에 따른 생산 병목을 설명하는 커뮤니티 가이드다.
- [Gala — The Town Star Rulebook](https://news.gala.com/common-ground-world/the-town-star-rulebook/)은 생산 사슬과 한 시설의 여러 제품을 확인할 자료다.

## 게임에서 적용하는 규칙

| 항목 | 타운그리드 |
|---|---|
| 시작 선택 | 비수도권 빈 부지를 고르고 첫 건물도 자유롭게 선택한다. |
| 시작 운송·보관 | 소형 트럭 1대·연료 40개·용량 160의 미니 창고. 별도 창고 없이 생산물을 받고 수입·수출한다. |
| 연료 | 모든 새 운송 수단이 거리별 연료를 쓴다. 소형 증류소는 시작부터 밀·목재·물로 연료를 만든다. 시장 수입도 가능하며, 연료가 없으면 판매처의 왕복 연료값까지 지불한다. |
| 창고 | 장소별 실제 재고를 보관한다. 창고·보관소를 추가하고 가까운 곳으로 운반한다. 일반 창고의 용량은 상품 전체 수량이고, 자재 보관소는 한 종류 전용으로 바꿀 수 있다. |
| 창고 정리 | 주민에게 다른 창고로 옮기게 하거나 예약되지 않은 물자를 폐기한다. 물자를 비운 창고는 철거할 수 있다. |
| 운송 | 선택한 항구·터미널을 지난다. 외부 도시까지 왕복 시간이 있고 판매 대금은 도시 도착 시, 수입품은 보관 장소로 귀환할 때 받는다. |
| 주민 | 주택에서 실제 주민이 생긴다. 건물마다 장식 일꾼을 추가하지 않는다. 일감이 없으면 집에 들어갔다가 새 일이 생기면 나온다. |
| 배치 수정 | 시설 이전으로 ID·재고·생산 진행을 유지한다. 이전 비용과 작업 시간이 든다. |
| 생산 사슬 | 농업·제분·제빵·축산·목재·금속·연료·화학·자동차·비공정으로 연결한다. 대안 제품과 관·컨베이어 직송을 지원한다. |
| 배치 효과 | 물·그늘·바람막이·오염·소금기·침수·같은 시설 모으기·목초지·클로버가 실제 생산에 영향을 준다. |

## 타운스타 대조 반영 (2026-10-03)

고전 서버(2020~2022)의 위키·클라이언트 데이터와 2024년 이후 공식 안내를 대조해 타운그리드에 없던 장치 11가지를 넣었다. 1인용 게임이므로 다른 플레이어가 하던 역할은 컴퓨터 상회와 이웃 나라가 맡는다. 수치와 측정 결과는 [밸런스 문서 22절](BALANCE_PATCH_20260928.md#22-타운스타-대조-반영-2026-10-03)에 있다.

| 타운스타 장치 | 타운그리드 적용 |
|---|---|
| 분당 임금과 파산 압박 | 등록 사업주부터 시설 운영비가 매일 건설비의 1.5%, 법인 대표부터 3%다. 꺼 둔 시설은 4분의 1을 낸다. 자금이 0 아래면 운반 65%에 더해 시설 생산도 75%로 떨어진다. |
| 강한 근접 벌점 | 새 지도에서 그늘·바람막이·오염 1점마다 생산 시간이 1.2배가 된다(최저 속도 25%). 예전 규칙보다 약해지지 않는다. 운영 카드가 가장 느린 시설과 더 빠른 자리를 알려 주고 바로 옮긴다. |
| 지형 매각 | 사막 유정의 채굴권(+400G, 원유 농도 40%로 내려감)과 습지 갈대 채취권(+60G)을 칸 정보에서 한 번 판다. |
| 장애물 제거 비용 | 준자유민부터 건설 자리의 나무는 8G, 바위는 20G를 내고 치운다. 목재·석재 2개는 그대로 얻는다. 농노 시절에는 부역으로 무료다. |
| 일일 도전 | 매일 별 목표가 생긴다. 최근 사흘 평균의 80%에서 시작해 연속으로 달성하는 날마다 8%씩(최대 6일) 오르고, 달성하면 목표 별 1개에 0.5G를 받는다. |
| 점수·순위·주간 경쟁 | 판매·납품이 도착하면 별을 받는다(목록가 10G마다 1개, 납품 1.5배). 7일마다 컴퓨터 상회 7곳과 순위를 매겨 1~5위에 상금을 준다. |
| 이웃 마을 배송 | 이웃 나라에 물건 1개를 30초마다 선물한다. 관계가 오르고 별을 받으며, 관계 60·75·90에 처음 닿으면 답례금을 받는다. |
| 계절 행사 | 순위 한 주가 한 계절이다. 봄 꽃 축제·여름 항구 축제·가을 수확제·겨울 등불제가 차례로 열려 해당 상품 값이 20~30% 오른다. |
| 오프라인 진행 | 저장한 마을을 이어하면 닫혀 있던 실제 시간(최대 30분)만큼 생산·운반·자동 판매가 진행된다. 그동안 사건은 시작되지 않는다. |
| 품목별 전용 창고 | 자재 보관소를 작물·자재·물·연료 전용으로 바꾸면 그 상품만 받고 1,440·1,440·2,400·720개를 담는다. 일반 창고는 그대로 모든 상품을 담는다. |
| 상위 일꾼 장비 | 운반 장비를 들인다. 손수레(계약 농노, 400G·판재 12)는 한 번에 4개, 짐마차(지역 납품업자, 1,800G·판재 20·벽돌 10)는 5개를 나른다. |
| 남겨 둘 양(자동 판매 설정) | 상품마다 보관 상한을 정하면 상한에 닿은 상품은 더 나르지 않고 생산 시설이 쉰다. |

정확한 수치는 [밸런스 문서 20절](BALANCE_PATCH_20260928.md#20-시작-물류실제-재고시설-이전)을 따른다. 픽셀 원화, 가상 대륙의 14개국, 33단계 성장·외교·방어는 타운그리드 자체 구성이다. 일반 창고에 품목별 전용 저장소 제한을 강제하지 않는다. 전용 보관은 자재 보관소에서 고르는 선택이다.
