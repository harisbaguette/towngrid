# Town Star 참고 규칙과 타운그리드

Town Star의 시작 물류·연료·보관·운반을 참고한다. 아래 자료의 연도별 가격을 현재 라이브 수치로 취급하지 않으며, 타운그리드의 비용과 용량은 자체 설계다.

## 참고 자료

- [Gala 공식 시작 안내](https://news.gala.com/common-ground-world/getting-started/)는 초기 가솔린 40개, 생산을 통한 연료 자급, 묶음 판매, 창고 용량, 일이 없을 때 귀가하는 주민을 설명한다.
- [Learn Town Star — 초기 경제와 가솔린](https://learntownstar.com/beginners-guide/how-to-make-gasoline/how-to-build-an-economy-in-town-star-for-gasoline-production/)은 초기 운송 거점·연료 저장소, 추가 창고, 운반 거리에 따른 생산 병목을 설명하는 커뮤니티 가이드다.
- [Gala — The Town Star Rulebook](https://news.gala.com/common-ground-world/the-town-star-rulebook/)은 생산 사슬과 한 시설의 여러 제품을 확인할 자료다.

## 게임에서 적용하는 규칙

| 항목 | 타운그리드 |
|---|---|
| 시작 선택 | 비수도권 빈 부지를 고르고 첫 건물도 자유롭게 선택한다. |
| 시작 운송·보관 | 소형 트럭 1대·연료 40개·용량 160의 미니 창고. 별도 창고 없이 생산물을 받고 수입·수출한다. |
| 연료 | 모든 새 운송 수단이 거리별 연료를 쓴다. 소형 증류소는 시작부터 밀·목재·물로 연료를 만든다. 시장 수입도 가능하며, 연료가 없으면 판매처의 왕복 연료값까지 지불한다. |
| 창고 | 장소별 실제 재고를 보관한다. 창고·보관소를 추가하고 가까운 곳으로 운반한다. 용량은 품목별이 아닌 상품 전체 수량이다. |
| 창고 정리 | 주민에게 다른 창고로 옮기게 하거나 예약되지 않은 물자를 폐기한다. 물자를 비운 창고는 철거할 수 있다. |
| 운송 | 선택한 항구·터미널을 지난다. 외부 도시까지 왕복 시간이 있고 판매 대금은 도시 도착 시, 수입품은 보관 장소로 귀환할 때 받는다. |
| 주민 | 주택에서 실제 주민이 생긴다. 건물마다 장식 일꾼을 추가하지 않는다. 일감이 없으면 집에 들어갔다가 새 일이 생기면 나온다. |
| 배치 수정 | 시설 이전으로 ID·재고·생산 진행을 유지한다. 이전 비용과 작업 시간이 든다. |
| 생산 사슬 | 농업·제분·제빵·축산·목재·금속·연료·화학·자동차·비공정으로 연결한다. 대안 제품과 관·컨베이어 직송을 지원한다. |
| 배치 효과 | 물·그늘·바람막이·오염·소금기·침수·같은 시설 모으기·목초지·클로버가 실제 생산에 영향을 준다. |

## 타운스타에 있고 타운그리드에 없는 것 (2026-10-03 조사)

고전 서버(2020~2022)의 위키·클라이언트 데이터와 2024년 이후 공식 안내를 기준으로 대조했다. "첫 1시간 우선" 원칙(AGENTS.md)에 따라 새 시스템은 아래에 기록만 하고 구현하지 않았다. 이미 비슷한 장치가 있는 항목은 오른쪽 열에 적는다.

| 타운스타 장치 | 내용 | 타운그리드 현재 |
|---|---|---|
| 분당 임금과 파산 압박 | 시작 $25,000에서 일꾼·시설 임금이 1분마다 빠진다. 일이 없어도 나가며, 돈과 휘발유가 함께 떨어지면 사실상 진행이 멈춘다 | 매일 유지비(5G + 건물 수 + 채무 이자 등)와 13단계부터 운영비(건설비 3%)만 있다. 적자일 때 운반 속도 65%, 회생 자금이 있다 |
| 강한 근접 벌점 | 불리한 이웃 1점마다 생산 시간이 2배(×2·×4·×8). 풍차를 붙여 지으면 30초가 240초가 된다 | 그늘·바람막이 단계 감속, 소금기, 침수 ×0.7 등 완만한 보정 |
| 지형 매각 | 연못 +$5,000(이후 $2,500), 사막 유정 +$25,000로 초반 현금을 만든다 | 없음. 연못은 지어서 물 공급원으로 쓴다 |
| 장애물 제거 비용 | 나무 $15,000, 바위 $40,000 등 | 건설 자리의 나무·바위는 무료로 치우고 목재·석재 2개를 얻는다 |
| 일일 도전 | 매일 0시(UTC) 초기화, 끝낼 때마다 목표가 500 → 8,000 Stars로 오른다 | 없음. 영주 납품 계약이 비슷한 반복 목표다 |
| 점수·순위·주간 경쟁 | 판매마다 Stars, 순위표, 6일·72시간 경쟁과 보상, 경쟁마다 마을 초기화 | 없음(1인용 캠페인). 완주 기록과 대륙 기록 5종만 있다 |
| 이웃 마을 배송 | 다른 플레이어 마을에 물건 1개를 30초마다 보낸다 | 내 거점 사이 운송만 있다 |
| 계절 행사 | 겨울·발렌타인·핼러윈 한정 작물·상품·장식 | 없음 |
| 오프라인 진행 | 2023년 이후 판본은 접속하지 않아도 마을이 돈다 | 없음. 브라우저를 닫으면 멈춘다 |
| 품목별 전용 창고 | 사일로·나무 창고·연료 저장소·급수탑 등 품목군마다 다른 창고와 용량 | 의도적으로 두지 않는다. 모든 상품을 담는 창고 하나와 보관소를 쓴다 |
| 상위 일꾼 교체 | 농부 → 트랙터(약 2배), 벌목꾼 → Logger 등 일꾼 자체를 비싼 장비로 바꾼다 | 말 축사(운반 ×1.35)·자동 물류센터(×1.65)·포장 도로가 비슷한 역할을 한다 |

정확한 수치는 [밸런스 문서 20절](BALANCE_PATCH_20260928.md#20-시작-물류실제-재고시설-이전)을 따른다. 픽셀 원화, 가상 대륙의 14개국, 33단계 성장·외교·방어는 타운그리드 자체 구성이다. 일반 창고에 품목별 전용 저장소 제한을 강제하지 않는다.
