# Town Star 조사와 타운그리드의 적용 규칙

검토일: 2026-09-26. 아래는 직접 열어 확인한 Gala 공식 자료와 현재 구현의 대응이다. 2022년 수치를 현재 라이브 서버의 정확한 밸런스로 취급하지 않는다. 타운그리드의 비용·시간·범위·승급 수치는 자체 설계다. 2026-09-28 밸런스 패치의 근거와 수치는 `BALANCE_PATCH_20260928.md`에 있다.

## 확인한 공식 자료

1. [Gala — The Town Star Rulebook](https://news.gala.com/common-ground-world/the-town-star-rulebook/), 2022-01-04. 상시 기본 규칙과 주간 변경 규칙, 묶음 판매, 생산 시간, 배치 영향이 구분되어 있다. 이 페이지가 연결하는 전체 스프레드시트의 최신 탭까지 검증했다고 주장하지 않는다.
2. [Gala — Getting Started with Common Ground World](https://news.gala.com/common-ground-world/getting-started/), 2024-09-05. 생산망과 정제 상품, 운송 연료, 창고 용량, 도로, 수질·그늘·오염의 배치 관계를 설명한다.

## 규칙별 대응

| 참고한 구조 | 타운그리드에서 실제로 하는 일 | 자체 변경 / 구분 |
|---|---|---|
| 원료를 고부가 상품으로 가공 | 밀 → 밀가루 → 빵·케이크, 목화 → 직물 → 작업복, 생선 → 훈제 생선 → 통조림, 석재 → 벽돌·유리·콘크리트, 광석·석탄 → 강철, 구리 → 전선 → 회로, 원유 → 연료·합성 소재, 자동차·의약품·마력등·마력 기관·미스릴 강 → 비공정 | 자원 36종, 시설 69종(생산 39종). 정제 단계마다 값이 오르고, 가공 시설은 원료 사슬보다 같은 땅에서 1.15배 이상 번다. 마력 결정이 현대산업과 결합한다. |
| 실제 운반에 의한 생산 병목 | 주민이 창고·시설 사이를 경로 탐색하며 원료와 제품을 운반한다. | 주민 고용·임금 관리는 사용자 요구로 제외. |
| 담수 인접 효과 | 밀밭·목화밭·약초원에서 두 칸 이내 담수 또는 가동 중 급수탑을 이용하면 물 운반과 재료 소비를 생략한다. | 반경은 대각선을 포함한 정사각 거리. 해안 바닷물은 관개에 쓰지 않는다. |
| 오염과 그늘 | 가동 가능한 오염원 주변 농업 효율 저하. 높은 건물은 중지해도 그늘을 만든다. | 오염 6·그늘 3단계 상한. 농업 속도 하한 40%. 배치 전과 시설 창에서 확인한다. |
| 풍력 주변 장애물 | 제분소·풍력기는 높은 건물에 가까울수록 느려진다. | 바람막힘 최대 3단계, 단계당 20% 감속. |
| 도로와 이동 | 도로에서 주민 이동이 빨라진다. 주요 산업 시설은 상하좌우 도로 인접이 필요하다. | 창고까지 걸어갈 통로도 필요하다. 운송 실패 원인을 별도 표시한다. |
| 유한 창고 | 자원별 기본 240개(등록 농노부터 270개), 자재 보관소마다 120개 증가. 수입·운반 예약도 용량을 검사한다. | 가득 차면 제품은 생산 시설에, 도착 화물은 노선에 보존된다. 철거나 운반 취소로 돌아온 물건은 한도를 넘어도 보존하고 한 번 알린다. 플레이어가 재고를 정리하면 이어진다. |
| 10개 단위 판매 | 자동 판매는 원료·계약·노선 예약을 남기고 10개(무역로 수량이 10 미만이면 그 수량)가 모이면 무역로 한도까지 출하한다. | 자동 출하는 8초 간격. 수동 소량 거래는 허용한다. |
| 기본 수출길 | 모든 지도에 서쪽 끝 관문 (0,11)에서 시작 땅까지 이어지는 8칸 수출길이 처음부터 깔려 있다. 판매한 상품은 창고에서 수출 마차에 실려 관문까지 가고, 마차가 관문에 도착해야 대금이 들어온다. | 수출 마차는 동시에 3대까지 운행하고, 대륙 거래소가 가동하면 5대가 된다. 창고가 없거나 길이 막히면 판매할 수 없고 재고는 그대로 남는다. 수출길은 철거하거나 그 위에 건설할 수 없고, 창고에서 관문까지 하나뿐인 길을 막는 자리에도 건물을 지을 수 없다(흙길·철도는 가능). 자동 판매가 길 막힘으로 멈추면 한 번 알린다. 계약 납품·수입·국가 교역은 아직 즉시 처리된다. |
| 무역로별 판매 | 모든 지역은 육로(비단길·포장 무역로, 또는 시골길·산길 합류)와, 닿아 있는 물길의 항구로 세계 무역망에 연결된다. 한 번에 보내는 수량은 바다 연안항 200, 강 항구·호수 항 100, 운하·하천 선착장 30, 작은 수로 나룻터 10, 포장 무역로 40, 비단길 30, 시골길 10, 산길 8이다. 연결에 따라 값도 달라진다. | Town Star의 고정 수출 규칙 대신 쓰는 자체 설계다. 항구 수량은 사용자 지정값이고 값 보정은 임시 설계값이다. 연결이 여럿인 지역은 판매 패널에서 고른다. 막힘·통행세·건설은 없다. |
| 상품 운송 비용 | 다른 거점으로 보내는 트럭·철도 화물에 비용·시간과 위험이 있다. | Town Star의 초기 가솔린 40개 및 주간 경쟁 스코어를 복제하지 않는다. |

## 사용자 기획을 유지한 확장

- 건물 하나는 타일 한 칸. 지역 안에서 인접 부지를 넓히고 세계 지도에서 다른 거점을 연다.
- 가상 대륙 하나, 중앙 내해와 네 강, 30개 초기 국가. 국가 정책과 개별 타일 효율은 별도로 작동한다.
- 인족·엘프족 두 종족을 선택한다. 인간·드워프·티탄 또는 엘프·정령·켄타로스·요정이 구성원으로 합류한다. 구성원이 현대산업 해금을 막지 않는다.
- 농노에서 패권국까지 33단계. 빚·가족·교역·투자·방어·외교·자치가 진행 조건에 연결된다.
- 재해·질병·파업·압박·침입과 신생국의 재분열은 별도 게임 시스템이다. 현재 국경·외교는 수치 시뮬레이션이며 전술 전략 게임 전체와 동일하지 않다.
- NFT, 토큰 판매, P2E 경제는 넣지 않는다. Town Star의 코드·시각·사운드 에셋은 사용하지 않는다.

## 검증

`tests/export-route.mjs`: 세 지역의 수출길, 창고 없는 판매 거부, 관문 도착 시 대금 지급, 마차 3대 제한, 운행 중 저장·불러오기, 마차 복귀, 수출길 보호, 길을 끊는 건설 거부, 길이 막혔을 때의 재고 보존과 자동 판매 알림, 기존 저장의 수출길 복원, 조작된 경로 거부, 초반 마을과 시연 마을의 수출.

`tests/trade-routes.mjs`: 물길별 항구 수량, 모든 지역의 육로 연결, 10종 연결 사용, 강 하구·중상류 항구, 호수 안에 지역 없음, 수량을 넘지 않는 판매와 자동 판매, 연결 선택에 따른 수량·값 변화, 닿지 않는 연결 거부, 저장·불러오기, 사라진 연결 ID의 자동 전환, 조작된 값 거부, 기존 저장 호환, 캠페인 거점별 지역 사용.

`tests/overhaul.mjs`: 담수/해수 구분, 무급수 관개, 오염원 중지와 그늘 유지, 풍력 방해, 도로 요구, 창고 제한, 화물 대기 후 정확히 한 번 하역, 기존 저장 호환.

`tests/full-campaign.mjs`: 정상 비용을 지불하는 플레이 행동으로 53일·6거점·자동차 120대·비공정 23척·패권국 도달. 구간 종료일·같은 날 승급 횟수·자금 부족일·승급 간격·구간 수입 기준(A1~A5)을 함께 검사한다. 도로도 실제 건설 행동으로 설치한다. 재화·실적·신분을 주입하지 않는다. 재미·난이도의 인간 플레이 승인을 대체하지 않는다.
