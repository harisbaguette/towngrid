# 캐릭터 전체 동작 체크리스트

**전 캐릭터·전 동작 작화는 미완료다.** 현재 게임에 51명과 11개 동작의 재생 데이터는 있지만, 모든 동작을 완성된 신규 작화로 교체한 상태는 아니다. 아래 완료 칸은 모두 열어 둔다.

이 체크리스트의 대상은 일반 일꾼 7명·직업 인물 38명·적대 인물 6명이다. 동작은 대기, 걷기·이동, 운반, 작업, 들기, 놓기, 인사, 공격, 피격, 쓰러짐, 회전의 11종이며 각 동작을 SW/NW/NE/SE에서 확인한다.

## 파일·연결 누락 확인

- [x] 게임의 캐릭터 ID 51개와 실행 팩·원본 명세·카탈로그 일치. 누락·중복·미등록 ID 없음.
- [x] 51명 × 11동작 = **561개 동작 항목**에 재생 프레임 존재.
- [x] 561개 동작 × 4방향 = **2,244개 방향별 동작 항목**에 비어 있지 않은 프레임 존재.
- [x] 51명의 정지 초상화와 호흡 일러스트 파일 존재.
- [x] 아틀라스 39,168셀의 빈 셀·경계 잘림·잘못된 발 기준점 없음.
- [x] 연결된 원본 파일 존재, 기록된 원본 해시와 현재 패킹 데이터 일치.
- [x] 실제 캐릭터 미리보기에서 51명과 11개 동작 버튼, 이미지 로딩 확인.
- [ ] 전 캐릭터의 전 동작 신규 작화와 연속 재생 품질 완료.

위에서 체크된 항목은 파일·재생 연결 검사다. 보행의 자연스러움이나 작화 완료를 뜻하지 않는다.

## 인물별·동작별 완료 체크

`□숫자`는 **완료 미체크 / 현재 재생 순서의 프레임 수**다. 예를 들어 `□32`는 32프레임이 존재하지만 작화 완료가 아니라는 뜻이다. 반복 노출·역재생·변형으로 만든 프레임도 이 숫자에 포함된다. 새 원화 장수나 서로 다른 자세 수로 읽지 않는다.

한 칸은 해당 인물·동작의 네 방향을 모두 포함한다. 네 방향의 연속 재생과 아래 완료 기준을 만족한 뒤에만 `☑`로 바꾼다. 현재 최종 완료로 체크한 인물은 **0/51명**, 동작은 **0/561개**다.

## 동작별 완료 기준

아래 항목은 위 표의 모든 인물에게 적용한다. 켄타로스·요정·정령은 사람 보행 기준을 그대로 적용하지 않는다.

- [ ] **대기:** 발 또는 부유 높이를 유지하고 호흡이 목·얼굴·장비를 찌그러뜨리지 않는다.
- [ ] **걷기·이동:** 좌우 디딤이 교대하고 체중 이동, 발끝 이탈, 다리 통과, 팔의 반대 운동이 이어진다. 접지 중 미끄러지거나 한 다리가 갑자기 짧아지지 않는다.
- [ ] **운반:** 걷기 조건을 유지하면서 양손과 화물이 붙어 있고 무게를 든 자세가 읽힌다.
- [ ] **작업:** 직업과 도구에 맞는 준비·실행·복귀가 있으며 도구와 손이 분리되지 않는다.
- [ ] **들기:** 물건에 손이 닿고 몸이 낮아진 뒤 물건과 함께 일어난다.
- [ ] **놓기:** 물건을 지면에 두고 손을 뗀 뒤 몸이 돌아온다. 역재생 여부와 별개로 이 순서가 자연스럽다.
- [ ] **인사:** 팔·손의 인사 동작과 몸의 반응이 이어지고 얼굴·어깨가 깨지지 않는다.
- [ ] **공격:** 준비·타격·회복을 구별하고 발 디딤과 몸의 힘 전달, 무기 궤적이 맞는다.
- [ ] **피격:** 공격·운반·작업 중 피격 전환에서 몸과 물건이 튀지 않고 반응이 읽힌다.
- [ ] **쓰러짐:** 무게 중심이 내려가며 지면에 닿는다. 팔다리·날개·꼬리가 분리되거나 바닥을 뚫지 않는다.
- [ ] **회전:** 네 방향 전환에서 축이 되는 발과 몸 중심이 맞고 방향 전환 전후에 자세가 튀지 않는다.
- [ ] **켄타로스 2명(카이·라나):** 네 다리의 순서, 앞뒤 다리 겹침, 몸통과 화물의 흔들림이 맞는다.
- [ ] **요정 2명(피아·에일):** 날갯짓·부유·방향 전환·운반 자세가 이어진다.
- [ ] **정령 2명(이슬·안개):** 부유 높이·몸과 꼬리 흐름·손과 화물의 위치가 이어진다.

## 방향·전환·화면 검수

동작 파일이 있어도 아래 전환에서 품질이 깨지면 해당 인물의 관련 동작 칸을 완료로 바꾸지 않는다.

- [ ] 각 인물의 SW/NW/NE/SE에서 실루엣·크기·발 기준점·손과 장비가 일치한다.
- [ ] 출발 → 걷기 → 정지에서 끊김·급격한 체중 이동이 없다.
- [ ] 들기 → 운반 → 상자를 든 정지 → 놓기에서 화물이 튀거나 사라지지 않는다.
- [ ] 걷는 도중 모퉁이를 돌거나 카메라를 90도 돌려도 디딤과 방향이 맞는다.
- [ ] 대기/작업 → 공격 → 피격 → 쓰러짐 전환이 읽힌다.
- [ ] 흙·도로·철도·관/컨베이어와 건물 앞뒤에서 발·그림자·가림 순서가 맞는다.
- [ ] 실제 게임 크기, 확대, CPU 렌더러, 주민 패널, 모바일에서 연속 재생을 확인한다.
- [ ] 큰 일러스트와 SD 동작의 얼굴·복장·체형이 같은 인물로 보인다.
