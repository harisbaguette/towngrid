게임 속 시설·주민·환경의 그림은 픽셀 계열이다. 모든 화면 요소가 픽셀 그림인 것은 아니다. 세계 지도의 국경·격자·글자, 버튼의 선 아이콘, 선택 표시·체력 막대는 SVG 또는 렌더러 도형이다.

## 이번에 정리한 잔재

시작 시 쓰이지 않는 옛 GLB 모델 요청이 84건 발생했다. `assets.js`는 이제 픽셀 팩만 읽으며, `models.js`의 구형 입체 건물·임시 상자와 `scene.js`의 비픽셀 경비병 장식 경로를 제거했다. 현재 시설 전체가 게임 진입점에서도 픽셀 그림으로 생성되는지 검사한다. 신규 시설에 작화 등록을 빠뜨리면 임시 입체 모형을 보여 주지 않고 누락을 알린다.

옛 GLB 파일과 이전 화면 원본은 보존 자료다. 현재 게임에서 로딩하지 않는다. `tests/asset-pose.mjs` 등 옛 모델 전용 검사는 보존 자료를 직접 읽으며 현재 게임의 시각 품질 검사가 아니다.

기존 작업 로딩 6장은 매끈한 애니메이션풍이었다. 같은 인물을 픽셀 화풍으로 다시 그리고 광산 공방·관개 온실·설원 철도·항구 배송·숲속 목공·차량 정비를 반영했다. 대기·홈·기본 로딩에는 광산, 설산, 내해 항만과 화물 운송을 보강했다. 화면 원화는 실제 지도 캡처가 아니라 게임 배경을 표현한 일러스트다.

## 추가 제작이 필요한 부분

1. **운송수단 동작:** 말 다리 보행, 바퀴, 배의 추진부, 항공기 프로펠러 등 별도 동작 프레임. 현재 네 방향 정지 원화와 실제 이동·적재 표시는 적용돼 있다.
2. **시설 작업 동작:** 항구 크레인의 상하차, 관·컨베이어의 개별 화물 이동. 시설 본체를 흔드는 대신 작업 부품과 화물을 분리해 실제 상태에 연결해야 한다.
3. **시설별 심한 파손:** 지금은 공통 균열·잔해 레이어다. 시설별 무너진 실루엣이 필요하면 별도 작화가 필요하다.

캐릭터 관절 마감은 51종에 반영했다. 관절 틈·겹침, 장갑·손 조각, 꼬리·날개 분리와 쓰러짐 무릎을 보완했다. [수정 전후와 검증](verification/character-finish-20260929/README.md)에서 확인한다. 원화 부위를 관절로 움직여 구운 프레임이며, 전 프레임을 새로 손작화한 방식은 아니다.

사막 유정·습지 나루터·화산 고원 대장간·설원 배송·해안 어업은 일상 그림에 추가했다. 세계 지도 지형 표식이나 기능 아이콘을 전용 픽셀 아이콘으로 통일하는 작업은 별도 선택 사항이다.

## 스크립트로 그린 신규 그림 — 2026-09-29 확장

확장 시설 22종(`docs/EXPANSION_20260929.md`)의 네 방향 본체, 밭 8종의 작물 성장 4단계(포도는 붉은/흰 두 줄), 새 상품 35종 아이콘, 양봉장의 벌 떼 부품은 **이미지 모델 원화가 아니다.** 이미지 생성 도구가 없어 `art-source/pixel-environment/farm-v9/`의 Python 스크립트가 작은 입체 칸 모형과 2D 도형을 픽셀로 찍어 만들었다. 같은 스크립트로 언제든 똑같이 다시 만들 수 있다.

기존 82종에 맞춘 부분:

- 1×1 정방형 바닥, 기존 밭 받침과 같은 크기·바닥선(181px), 행 순서 SE → NE → NW → SW의 192×768 아틀라스.
- 본체 고정. 작물·도구·완성품은 따로 올리며 실제 진행률·가동·재고·공급 시간을 읽는다. 뒤에 가려지는 부품 위치는 시점별로 끈다.
- 밭 8종은 작물과 소품(물길·소금 증발지·포도 시렁·건조대·짚 덮개·돌 두둑·허수아비·통나무 더미)으로 서로 구별한다. 목축 시설은 양·젖소·오리·벌통을 본체 안에 넣었다.
- 손상은 다른 시설과 같은 공통 균열·잔해·수리 표시를 쓴다.

눈으로 본 결과(`docs/verification/expansion-art-20260929/`): 네 방향 모두 시설 종류는 알아볼 수 있다. 다만 기존 원화보다 세부가 적고 덩어리가 단순하며, 외곽선이 조금 가늘다. 나란히 놓으면 같은 게임 안에서도 손으로 그린 원화와 차이가 보인다.

이미지 모델로 다시 그려야 할 후보(품질이 낮은 순):

1. **태양광 패널** — 북동·북서 시점에서 패널 뒷면이 원통처럼 보인다.
2. **밀랍 아이콘** — 벌집 무늬 덩어리가 치즈처럼 읽힌다.
3. **양모 아이콘** — 작게 보면 흰 덩어리라 목화와 헷갈릴 수 있다.
4. **초콜릿 공방** — 초콜릿 지붕이 평범한 갈색 지붕으로 보인다. 시설을 알려 주는 것은 앞마당의 구리 솥뿐이다.
5. **목초지** — 풀 포기가 어지럽게 흩어져 보인다.
6. **포장 공방** — 지붕 위 상자 말고는 일반 창고와 비슷하다.
7. **사료 공장** — 사일로가 높아 건물 아이콘에서는 윗부분이 잘린다.
8. **양봉장** — 벌통 지붕이 작은 집처럼 보인다.
9. **크롬·석회암 아이콘** — 광물 덩어리의 형태가 단순하다.
10. **밭 표지판** — 6×6칸 그림이라 실제 화면에서는 내용이 거의 읽히지 않는다. 밭의 구별은 작물과 소품이 맡는다.

남은 한계:

- 동물·벌 떼는 멈춘 그림이다. 양·젖소·오리의 걷기·먹기 동작은 없다. 벌 떼는 가동 중에만 떠오르는 한 장이다.
- 작업 부품은 기존 도구 아틀라스(프레스·바퀴·불꽃·증기·곡괭이·표시등·소포)를 다시 쓴다. 포도 압착기 나사·솥 젓개 같은 전용 부품은 없다.
- 뒤쪽 시점에서는 일부 대표 설비가 건물에 가려진다(와이너리 오크통, 초콜릿 솥 등). 본체 모양과 색으로 구별해야 한다.
- 연못·목초지·야생 클로버는 작업 주기가 없어 부품 없이 본체만 있다.
- 작물은 기존 목화·밀처럼 옆에서 본 평면 그림이다.

## 스크립트로 그린 신규 그림 — 2차 보완(2026-09-30)

`docs/EXPANSION_20260929.md` 6절의 시설 2종·상품 9종을 `farm-v9/`의 스크립트 그림으로 더했다. 이미지 모델 원화가 아니다.

- **얕은 광산**: 산 광산의 바위 더미 없이 평지에 판 네모 갱구, 나무 틀, A자 지지대와 도르래, 선로 위 광석 수레, 철·구리 광석 더미. 도르래는 채굴 중 돌아가는 부품이다.
- **풍력 양수기**: 가늘어지는 격자 철탑, 꼬리 날개, 펌프 막대, 나무 물통과 수로. 16날 바람개비는 별도 부품(`farmParts` 2번)이며 급수 중에 돌고, 네 시점에서 자기 수직면으로 투영된다.
- **상품 9종**(`farmGoods2`, 전체 72~80번째): 빵 반죽(나무 그릇), 바게트(엇갈린 두 개와 종이), 케이크 반죽(파란 그릇과 거품기), 고급 케이크(딸기 올린 초콜릿 홀케이크), 장식 케이크(박하 사탕 장식 2단), 와인병(라벨 없는 빈 초록 병 3개와 나무 받침), 상그리아(과일 든 유리 주전자), 벌집(나무 틀의 육각 벌집과 흐르는 꿀 — 말아 둔 밀랍과 구분), 항공유(파란 통과 흰 비행기 표시 — 노란 연료통·검은 원유통과 구분). 기존 71종의 순서와 그림은 그대로다.
- 파손 25% 화면에서 두 시설 모두 공통 균열·먼지 레이어가 나온다([화면](verification/expansion-art-20260930/damage-25-new-facilities.png)).

같은 날 1차 스크립트 그림 중 밭 표지판(무늬 2배), 양봉장(지붕 없는 상자 벌통 3개와 짚 벌통), 사료 공장(사일로 지붕이 칸 위로 잘리던 것), 와이너리(오크통·압착기가 뒤 시점에서 집 뒤에 가려지던 배치), 목초지(고르게 흩어진 풀 → 줄무늬 풀밭과 풀 무더기·물통), 크롬(금속 광택 덩어리)·석회암(크림색 블록과 조개 화석)을 `farm-v9/` 원본에서 다시 그렸다([전후 비교](verification/expansion-art-20260930/before-after-script.png)). 이 항목들은 같은 날 다른 작업에서 이미지 모델 원화(`farm-v11/`·`farm-v12/`)로 교체되며, 교체된 항목은 그 원화가 게임에 쓰인다. `farm-v9/build.py`는 교체된 항목의 패킹 명세를 덮어쓰지 않는다. 태양광 패널·밀랍·양모·초콜릿 공방·포장 공방은 `farm-v11/` 원화가 대신하므로 스크립트로 다시 그리지 않았다.

남은 한계:

- 두 시설과 상품 9종은 이미지 모델 원화 옆에 두면 덜 풍부한 입체 칸 그림이다. 이미지 모델로 다시 그릴 후보다.
- 풍력 양수기 물통은 북서 시점에서 탑 뒤에 가려진다. 얕은 광산의 갱구 안쪽은 지지대에 가려 어둡게만 보인다.
- 바람개비는 북동 시점에서 머리 뒤에 있지만 앞에 겹쳐 그린다. 광산 도르래는 기존 도구 아틀라스의 바퀴를 쓴다.
