# 타운스타 비교: 물류·성장 규칙

| 항목 | 타운그리드의 현재 규칙 |
|---|---|
| 시작 | 첫 건물은 자유 선택. 소형 트럭 1대·연료 40개·미니 창고 160개로 시작 |
| 실제 재고 | 창고마다 별도 재고. 생산 제품을 바꾸면 기존 상품·반환 재료는 시설에 남아 실제 운반을 기다림 |
| 수출 경로 | 건설 후 운행 중 차량도 우회. 막히면 화물을 보존하고 대기 |
| 연료와 차량 | 연결된 가동 창고의 연료만 소비. 사용 가능한 터미널만 차량을 배정 |
| 주문량 | 시장에서 수량·최대 적재를 선택. 수입도 차량 한도 적용. 큰 영주 주문은 분할 납품 |
| 창고 선택 | 창고 480개(등록 농노부터 600), 자재 보관소 1,200개. 각각 Lv.3까지 확장 |
| 비상 연료 | 증류소 한 곳. 연료 5개 미만일 때 밀 6·목재 3·물 2로 60게임초에 연료 1개. 업그레이드 불가 |
| 정규 연료 | 준자유민에 풍력·유정, 임차 사업주에 정유소. 원유 증류 8게임초→물 2개로 냉각·혼합 6게임초. 도로·전력 필요, 연료 3개 산출 |
| 업그레이드 | 주택 인원, 생산 속도, 보관 용량, 발전 용량, 터미널 적재량에 서로 다른 효과. 자재 기술·비용·수리 상태 적용 |
| 주민 | 주택에서만 등장. 증가 인원마다 유지비 1G/일 추가. 별도 고용 관리 없음 |
| 외부 운송 | 도로·선박은 연료, 열차는 석탄, 항공기는 항공유. 목적지 선택과 지형 경로 미리보기 제공 |

타운스타의 품목별 창고 분류와 달리, 타운그리드는 공용 창고마다 품목별 상한·입고 거부·예약 공간을 정한다. 위치·용량·운반 거리와 함께 관리한다. 건물 업그레이드는 게임 내 자재와 돈으로 올리는 3단계 방식이다. Common Ground World 자료의 NFT 업그레이드 체계를 그대로 적용하지 않는다.

대륙 교통은 세계 격자와 간선 회랑을 이용한 경로 계산이다. 철도·수운은 육상 환적을 포함하며, 대륙 전체의 개별 선로·교량을 플레이어가 건설하는 시스템은 아니다. 운송 그림은 기존 픽셀 차량·선박·열차·항공기 자산을 사용한다.

초보 안내는 운반 인원·손수레·원유·물 공급·전력 반경·도로 연결과 교역 거리에 맞는 연료 보충을 제안한다. 실제 소요 시간은 건설과 판매 선택에 따라 달라진다.

비교 자료:

- [Gala 공식 시작 안내](https://news.gala.com/common-ground-world/getting-started/): 초기 연료, 연료 자급, 유지비와 생산 성장.
- [Common Ground World Litepaper](https://news.gala.com/common-ground-world/common-ground-world-litepaper/): 업그레이드 구상. 일반 건물 전체에 동일한 업그레이드가 있다는 근거로 사용하지 않는다.
- [Learn Town Star 연료 경제](https://learntownstar.com/beginners-guide/how-to-make-gasoline/how-to-build-an-economy-in-town-star-for-gasoline-production/): 초기 생산·운반·보관 사슬.
- [Learn Town Star 시작 위치](https://learntownstar.com/beginners-guide/location-selection/choosing-a-starting-locationin-town-star/): 주변 지형과 교역 거리.

공식 입문 자료는 2024년, 커뮤니티 자료는 주로 2021~2022년 설명이다. 현재 라이브 게임의 가격표로 쓰지 않는다.

## 추가 보완 규칙

| 항목 | 현재 동작 |
|---|---|
| 분할 납품 | 주문이 14개이고 차량이 10개면 재고 10개로 첫 출발 가능 |
| 거점 간 운송 | 실제 창고의 재고·경로·입고 예약 확인. 이전·정지·파손 창고에서 출고하지 않음 |
| 취소된 운반 | 주민이 화물을 들고 반환. 창고가 가득 차면 기다리고 저장 후에도 이어 운반 |
| 수입 | 주문 버튼과 출발 조건 일치. 귀환 때 상한이나 공간이 부족하면 화물 유지 |
| 보관소 설명 | 실제 용량 계산을 사용해 업그레이드와 표시 일치 |
| 정규 연료 | 원유 증류와 냉각·혼합 공정. 냉각수 부족 시 중간 대기, 증설 시 원료·물·전력 수요 증가 |
| 전력 | 연결망별 공급량·시설별 부하. 작업 순서, 발전소 증설·업그레이드 반영 |
| 도시 선택 | 품목별 수요와 거리 보너스를 판매가에 반영. 출발 시 대금 고정 |
| 보관 조절 | 창고마다 품목별 입고 거부·상한·예약 공간. 기존 재고와 저장 유지 |
| 산업 도전 | 제빵·직물·제철 고정 도전과 주간 도전. 제한 시간, 결과·최고 점수·재도전. 캠페인 별도 저장 |

보완 항목은 [체크리스트](TOWNSTAR_IMPLEMENTATION_CHECKLIST.md), 실제 수치는 [밸런스 규칙 23절](BALANCE_PATCH_20260928.md#23-공정전력교역보관산업-도전)을 따른다.

타운스타의 원유→석유 중간재→가솔린 사슬은 연료 공급망의 깊이를 참고한 것이다. 타운그리드는 정유소 내부의 두 공정 외에도 석유 중간재와 공업용수를 별도로 생산·운반·혼합하는 생산법을 제공한다. [Learn Town Star 연료 경제](https://learntownstar.com/beginners-guide/how-to-make-gasoline/how-to-build-an-economy-in-town-star-for-gasoline-production/)

산업 도전은 세 고정 시나리오와 회차별 부지·목표·점수 규칙이 바뀌는 주간 도전이다. 기록은 로컬에 보관하며 온라인 사람 간 순위표는 제공하지 않는다. 타운스타/CGW의 대회 구조는 반복 플레이 목표를 만드는 참고로 사용했다. [Gala 공식 게임 모드 안내](https://news.gala.com/common-ground-world/getting-started/)
