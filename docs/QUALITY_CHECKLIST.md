- [x] 종족별 공격 특성이 실제로 다르게 작동한다.

- [x] 병원·축전지·복지 협약으로 각 위기에 대응한다.
- [x] 신생 국가가 성장하고 외교·교역의 대상이 된다.
- [x] 신생 국가가 다시 분열하고 세계 기록이 저장된다.
- [x] 지역 불만과 독립 가능성을 플레이어가 미리 확인할 수 있다.
- [x] 운송 중 화물은 출발/도착/저장 후 복원에서 정확히 한 번 처리한다.
- [x] 노선 수정·폐쇄 시 운송 중 화물이 사라지지 않는다.
