# 주민 작업 장면 시안

기존 캐릭터 일러스트의 외형과 의상을 바탕으로 만든 가로형 화면 배경 시안이다.
사용자가 첨부한 사무실 일러스트에서 햇빛, 생활감, 인물을 가까이 잡는 구도를 참고했다.

- `01-mira-workshop.png`: 미라의 차량 정비.
- `02-marna-workshop.png`: 마르나의 기계 조립.
- `03-silen-greenhouse.png`: 실렌의 마력 관개 설비 점검.

이전 대기·로딩·홈 화면 3장은 상위 폴더에 그대로 보관한다.
이 배경 3장은 승인 후 WebP로 변환해 로딩 화면과 홈의 '마을의 하루'에 적용했다. 캐릭터 스프라이트에는 적용하지 않는다.
참고 자산 경로와 생성 프롬프트는 `prompts.json`에 기록했다.
