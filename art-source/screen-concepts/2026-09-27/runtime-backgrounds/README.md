# 시작 화면과 주민 작업 일러스트

상위 폴더의 승인된 최초 PNG 3장은 수정하지 않고 보존했다.
대기·로딩·홈 시안에서 로고와 UI를 제거한 배경 PNG를 만들고, 기존 승인 로고와 실제 HTML 버튼을 게임에서 합성한다.

- `waiting-background.png`: 대기 화면.
- `loading-background.png`: 초기 준비 및 종족 자료 로딩의 기본 배경.
- `home-background.png`: 홈 메뉴.
- `rowan-rail.png`, `hana-dispatch.png`, `bron-carpentry.png`: 추가 주민 작업 장면.
- 기존 `../character-work-v1/`의 미라·마르나·실렌 3장을 합해 주민 일러스트는 총 6장이다.

원본 경로, 실행용 경로와 생성 프롬프트는 `manifest.json`에 기록했다.
`node scripts/pack-screen-art.mjs`가 잠금 파일에 이미 포함된 sharp로 WebP를 재생성한다. 새 패키지는 추가하지 않았다.
9개 원본은 합계 23,828,196바이트, 실행용은 3,730,916바이트다. 해상도를 유지하고 형식을 변환해 약 84% 줄였다.

그림 선택은 `src/app/game/screen-art.js`의 6장 묶음을 섞는 방식이다. 한 묶음 안의 중복과 묶음 경계의 연속 중복을 방지한다.
남은 순서와 마지막 그림은 별도 localStorage 키 `towngrid-screen-art-v1`에만 보관한다. 저장소를 쓸 수 없으면 메모리에서 작동한다.
로딩이 끝나면 즉시 전환하며, 오래 걸리는 로딩은 8초마다 그림을 바꾼다. 가짜 백분율과 최소 대기 시간은 두지 않았다.
빠르게 끝나는 로딩의 그림은 짧게 보이거나 거의 보이지 않을 수 있다. 홈의 '마을의 하루'에서 6장을 직접 넘겨볼 수 있다.
게임 중 일정 시간마다 화면을 가리는 팝업은 추가하지 않았다.

생성 이미지의 도구 접촉, 미세 작화와 모바일 세로 크롭은 수작업 아트 검수로 더 다듬을 수 있다.
