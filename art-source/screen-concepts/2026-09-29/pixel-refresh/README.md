# 픽셀 화면 원본

대기·홈·기본 로딩 3장과 주민 작업 장면 6장을 갱신한 원본이다. 이미지 생성 도구로 기존 화면을 참고해 새로 그렸다. 기존 승인 로고는 UI에서 별도로 표시한다.

`manifest.json`에 원본, 참조, 프롬프트, 실행용 경로를 기록했다. 재생성 명령은 `node scripts/pack-screen-art.mjs`다. 원본 크기를 유지한 WebP 9장, 합계 약 3.89 MB로 배포한다. 저장 형식과 로딩 그림 선택 이력 키는 바꾸지 않았다.

2026-09-27 원본은 이전 화면의 보존 자료다. 현재 실행용은 `public/assets/screens/pixel-v2/`다.
