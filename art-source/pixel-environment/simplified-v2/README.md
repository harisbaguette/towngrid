# 가독성 보정: 픽셀 화풍 유지

사용자 최신 지시: 타운스타처럼 작은 화면에서 시설의 기능이 뚜렷해야 한다. 기존 픽셀 화풍은 유지하며, 매끈한 3D·벡터 화풍으로 전환하지 않는다.

보정 대상은 이미 적용한 초반 건물 5종과 제재소다. 작은 기와·나뭇결·벽돌·소품을 줄이고, 실루엣·넓은 픽셀 색 덩어리·대표 설비를 강조한다. 카메라 4방향과 실제 상태 연동은 유지한다. 앞서 준비한 비픽셀 방향의 프롬프트는 폐기했으며 실행용 자산에 적용하지 않았다.

추가 기준: 실제 바닥은 가로·세로가 같은 1×1 정방형이다. 고도각 35.264°에서 가로:세로 약 √3:1 마름모로 투영된다. 본체와 부속 소품을 이 한 칸에 넣는다. `warehouse-style-study.png`는 픽셀 표현만 확인한 중간 시안으로, 길쭉한 바닥을 보정하기 전이며 실행용이 아니다. 최종 원본은 각 시설의 `*-source.png`다.

주택은 생성 결과의 연기가 지붕 반대편에 붙거나 다음 행으로 넘어가는 문제가 있어 이미지 생성 도구로 연기를 제거했다. 네 상태는 창문이 어두움 → 켜짐 → 밝아짐 → 켜짐으로 표현한다. 입주 여부와 게임 시간에 연결되며 기존 시뮬레이션을 바꾸지 않는다.
