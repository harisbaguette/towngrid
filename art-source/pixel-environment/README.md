# 픽셀 환경 샘플과 초반 건물

2026-09-27 사용자 요청에 따른 제재소·참나무·물 타일과 후속 초반 건물 5종 시험 교체본이다. 전체 환경의 픽셀 전환을 완료한 묶음이 아니다. 캐릭터 자산은 별도 작업에서 관리한다.

- `pilot-atlas-source.png`: 이미지 생성 도구로 제작한 최초 제재소, 나무 상태, 물, 판재 아이콘 원본.
- `sawmill-directions-source.png`: 최초 제재소를 참고해 생성한 4방향 × 4상태 원본.
- `warehouse/house/well/field/lumber-source.png`: 초반 건물 5종의 생성 원본. 생성 지시는 `starter-prompts.json`, 주택 굴뚝 연기 보정은 `starter-corrections.md`에 기록했다. `house-original-source.png`는 첫 결과 보존본이다.
- `pack-manifest.json`: 원본별 자르기 영역, 공통 배율, 바닥선, 앵커, 동작 명세.
- 실행용: `public/assets/pixel-environment/`. 192px 셀, RGBA, nearest filtering. 패킹 시 알파 160 미만을 제거하고 동일 개체의 모든 프레임에 같은 배율을 적용한다.

재패킹: 프로젝트 루트에서 `node scripts/pack-pixel-environment.mjs`. 기존 Wrangler → Miniflare의 sharp를 사용하므로 새 의존성을 추가하지 않는다.

## 화풍과 프레임

짙은 청록 윤곽선, 꿀색 목재, 청록 지붕, 올리브색 잎, 청록 수면으로 맞췄다. 광원은 좌측 위다. 사용자 참고 이미지의 소재를 참고해 새로 생성했으며, 참고 이미지를 잘라 배포한 것이 아니다.

| 자산 | 구성 | 실제 게임 연결 |
| --- | --- | --- |
| 제재소 | 4열 × 4행, 768×768 | 행 SE → NE → NW → SW. 열 0 대기, 1·2·3 생산. 가동 중지·고장·재료 부족 시 대기 |
| 창고 | 4열 × 4행, 768×768 | 실제 주민이 창고에서 상하차할 때 문 동작, 그 외 닫힘 |
| 주민 주택 | 4열 × 4행, 768×768 | 해당 집에 주민이 살면 굴뚝 연기. 종족별 특수 주택은 기존 아트 유지 |
| 우물 | 4열 × 4행, 768×768 | 실제 가동 시 물통 오르내림, 정지·고장 시 대기 |
| 벌목장 | 4열 × 4행, 768×768 | 실제 가동 시 통나무 인양, 원목이 없거나 정지하면 대기 |
| 밀밭 | 4열 × 4행, 768×768 | 생산 진행률에 따라 파종·새싹·생장·황금 밀. 정지하면 현재 성장 단계 유지 |
| 참나무 | 7열, 1344×192 | 잎 0·1·2, 채집 3, 그루터기 4, 묘목 5, 어린 나무 6 |
| 물 | 4열, 768×192 | 수면 3fps, 게임 시간과 일시정지를 따름 |
| 판재 | 192×192 | 게임의 판재 자원 아이콘 |

건물 6종은 카메라의 네 방향에 따라 행을 고른다. 나무는 동일한 수관을 재사용하고, 물은 지면에 놓여 지도와 함께 돌아간다. 건물 한 채는 기존대로 한 타일을 차지한다. 원근 없는 카메라의 고도각은 약 35.264°로 고정하며 수평각은 45° + 90° × 방향 번호다. 빌보드는 화면 위치를 유지한 채 시선 방향으로 보정해 지면이 건물 기초를 자르지 않도록 했다. 원본의 행 간격이 균등하지 않은 주택·밀밭은 `rowBounds`로 분리한다.

나무는 실제 가동 중인 벌목장이 고른 자원 타일에만 채집 프레임을 표시한다. 고갈 후 그루터기를 2.4초 표시한다. 그루터기는 일시적인 렌더링 상태로 저장하지 않는다. 조림은 기존의 15G·물 2와 성장 시간을 사용하며, 묘목/어린 나무를 거쳐 기존 시뮬레이션이 성목으로 바꾼다. 무료 자동 재생 규칙을 추가하지 않았다.

## 확인과 남은 한계

- 초반 건물은 `/` → **초반 마을 테스트**에서 확인한다. 창고 1·주택 3·우물 1·밀밭 2·벌목장 1·제재소 1과 주민 6명이 준비된다. 시작 자재·건물만 제공하고 실제 생산·물류 규칙을 사용한다. 기존 자동 저장은 덮어쓰지 않는다. `/pixel-environment-preview.html`은 최초 3종 상태 비교용이다.
- WebGL과 CPU 렌더러가 같은 PNG를 읽는다. 프레임 UV는 개체별이며 GPU 이미지 소스는 공유한다.
- 회전별 건물의 세부 구조와 프레임별 픽셀 정렬에는 생성 원본의 차이가 남아 있다. 승인 후 정밀 보정할 샘플이다.
- 별도의 쓰러지는 나무 중간 동작, 해안 거품/타일 접합 전용 아트, 피해·수리 전용 건물 아트는 없다.
- 나머지 건물·땅·암석·지도 밖 배경 수면은 기존 표현이다. 원거리 안개는 아직 적용하지 않았다.
- 이번 작업은 저장 형식·저장 키·게임 규칙·의존성 버전을 바꾸지 않는다.
