# 미라 1명 승인용 시안 — 2026-09-27

사용자가 전체 캐릭터 작업 전에 한 명을 먼저 보고 판단하도록 요청한 작업이다. **미승인 화풍 시안**이며 이 새 아트를 게임에 적용하지 않았다. 이후 사용자의 쿼터뷰 전환 지시로 방향 보기는 SW/NW/NE/SE 네 모습만 표시한다. 게임은 기존 24종 아트에서 같은 네 방향을 재패킹해 사용한다.

## 열기

- 개발 서버: `http://localhost:5173/character-preview/mira/index.html`
- 서버 없이: `public/character-preview/mira/index.html`을 브라우저로 연다.
- 원본과 좌표 명세를 다시 복사: 프로젝트 루트에서 `node scripts/pack-mira-preview.mjs`.

## 방향

사용자 두 번째 참고의 큰 머리와 읽기 쉬운 팔다리를 갖춘 약 4등신 SD를 목표로 한다. 세 번째 참고처럼 같은 인물의 고유 픽셀 일러스트를 제공한다. 미라의 갈색 포니테일, 청록 작업복, 크림색 상의, 가죽 공구 벨트와 황동 장식은 기존 정체성에서 이어왔다. 비율·얼굴·화풍의 최종 판정은 사용자에게 남아 있다.

`study.png`는 첫 일러스트/스타일 시트다. 이 시트의 작은 동작 행은 재생에 사용하지 않는다. 유사한 다리 자세가 반복되어 별도로 보완했다. `walk.png`는 8개 걷기 포즈, `motions.png`는 8방향 대기 모습과 대기·작업·인사·상자 상호작용 각 8개 포즈를 담은 보존 원본이다. 최신 미리보기에서는 방향 4개와 행동 40개, 총 44개 포즈를 사용한다.

## 프레임 관리

원본 PNG는 이미지 생성 도구 결과를 그대로 복사했다. PNG의 픽셀을 코드로 다시 그리거나 보간해서 새 작화로 주장하지 않는다. 브라우저는 `pack-manifest.json`의 원본 좌표에서 그림을 가져와 표시한다. 프레임별 발 기준점과 클립 공통 크기를 사용하고, 웅크린 그림의 높이를 억지로 늘리지 않는다. 원본, 명세, 실행용 이미지/좌표는 `scripts/pack-mira-preview.mjs`로 함께 관리한다.

`requestAnimationFrame`의 경과 시간으로 위치를 갱신한다. 위치 갱신은 포즈 교체와 별개이며 재생 속도를 바꾸면 두 속도가 함께 변한다. 이는 독립 시안에서 검토하는 방식이며 게임 이동 수정은 아니다.

## 남은 사항

- 걷기·행동 작화는 E 방향의 이전 시안뿐이다. 최신 네 대각선 방향의 행동 조합은 아직 없다.
- 방향 보기는 90도 간격 네 원화 재생이다. 현재 시스템은 자유 회전용 중간 작화를 요구하지 않는다.
- 공격·피격·사망, 작업별 도구 행동, 별도의 운반 보행은 없다.
- 포즈 간 얼굴·머리카락·실루엣 변화, 다리 교차의 좌우 구분과 보행 리듬을 더 정리해야 한다. 포즈 수만으로 자연스러운 모션 완성을 주장하지 않는다.
- 배경은 크림색을 포함한 원본이다. 게임용 투명 배경 아틀라스로 완성된 것이 아니다.
- 기존 주민 패널/3D 월드에 적용하지 않았으므로 그 화면에서의 카메라 회전·크기 검증은 아직 해당하지 않는다.
- `app/game/logistics.js`의 `moveWorkers`는 경로 한 지점까지의 거리만 소비한 뒤 다음 지점으로 남은 이동량을 넘기지 않는다. 지점마다 속도 손실이 생길 수 있는 구조이며 아직 수정하지 않았다. 기존 3포즈 걷기와 프레임별 비례 차이도 확인했다. 실제 게임 끊김의 전체 원인을 확정한 성능 계측은 아니다.
