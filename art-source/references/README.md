# 사용자 제공 참고 이미지

대화에서 직접 제공한 자료 중 아래 8개를 원래 파일명으로 포함했습니다. 로컬 Codex가 스타일 방향을 확인할 수 있도록 보관하는 참고 자료입니다. 게임 런타임에서 불러오는 자산은 `public/assets/`에 있으며, 승인된 실제 로고/심볼은 `public/assets/brand/`를 사용합니다.

참고 이미지를 게임 배포 자산으로 사용해도 되는 라이선스가 확인된 것은 아닙니다. 외부 참고 자료의 이용 허락과 TownGrid용 생성 원본/외부 에셋 라이선스는 구별합니다. 대화에 있었던 모든 과거 첨부 이미지와 생성 시안을 회수한 아카이브는 아니며, 위 목록이 이번 묶음에 포함된 참고 자료의 범위입니다. 최신 프로젝트에 저장된 게임 자산과 원본은 별도로 모두 보존했습니다.
